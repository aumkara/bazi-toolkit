# Конвенции калькуляторов: что выбрано, что есть в альтернативах, как переключить

Школы расходятся; калькулятор не может быть «просто правым» — он может быть **явным**. Каждая строка ниже отвечает на три вопроса: что считает код по умолчанию, какая альтернатива существует, как об этом узнаёт чтение (поле в JSON) и можно ли переключить. Формат — по образцу fortune-assistant (`docs/related_projects.md`, §4 п. 3). Issue #18. Использованные значения переключателей bazi.py печатаются в JSON `conventions.switches` — чтение по нестандартной школе обязано назвать их в Тени.

## Правило для скиллов

Конвенция, которая **меняет результат** для данной карты (23:00–23:59; близость к 节/立春; node-чувствительность; окно Личунь↔Лосар; 羊刃 инь-ствола), называется в «Тени» файла и — если переворачивает Хозяина Дня, Тип/Авторитет или Лагну — в `4_synthesis.md`. Остальные конвенции перечислять не нужно: они в JSON для воспроизводимости.
