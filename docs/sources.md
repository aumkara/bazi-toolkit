# Источники проекта: что откуда взято и какой у этого статус

Реестр источников, на которые **уже ссылаются код и справочники** (2026-11-09, issue #20). Ничего не добавлено «из памяти»: каждая строка — то, что названо в файле из колонки «Где». Статусы: **[факт]** — проверяемая таблица/расчёт, сверенные с независимой реализацией; **[факт традиции]** — так учит названная школа/текст, цитат дословно не даём; **[интерпретация]** — пересказ-синтез гайда; **[спекуляция]** — авторская конструкция. Правило для чтений: имя классика в гайде — указание на школу, не на пассаж; «как сказано в X» писать нельзя.

## Чего здесь нет

Пер-утверждение ссылок («тезис X — из главы Y») в `geju.md`, `60_pillars.md`, `tiaohou.md` и гайдах. Их не было в исходных текстах, и восстанавливать их по памяти значило бы выдумывать — это работа владельца с книгами в руках. До тех пор действует правило шапок: статус утверждения ([факт]/[интерпретация]) обязателен, цитаты классиков запрещены. Обзор сторонних проектов, откуда взяты приёмы (fact-check 干支, ретро-калибровка, формат конвенций, оракулы), — `docs/related_projects.md`.
