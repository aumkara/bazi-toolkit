# Безопасность

## Что считается уязвимостью

- **Локальная веб-версия (`web.py`).** Сервер слушает только `127.0.0.1` и отклоняет чужие `Host` и `Origin`.
  Уязвимость — любой способ с постороннего сайта или из сети получить ответ сервера, прочитать файлы с диска,
  выполнить команду либо обойти эти проверки.
- **MCP-сервер и калькуляторы.** Аргументы передаются в дочерний процесс списком, без оболочки. Уязвимость —
  значение аргумента, которое приводит к выполнению постороннего кода или чтению постороннего файла.
- **Личные данные в репозитории.** Реальные даты рождения, имена, домашние пути, адреса почты или токены в любом
  файле или коммите.

Не уязвимость: неточность расчёта или несогласие со школой — это обычный issue.

## Как сообщить

Через закрытое сообщение на GitHub: вкладка **Security** репозитория → **Report a vulnerability** ([прямая ссылка](https://github.com/aumkara/bazi-toolkit/security/advisories/new)). Не публикуйте
подробности в открытых issues и pull request'ах, пока исправление не вышло.

Проект ведёт один человек, сроки ответа не гарантируются. Исправления выходят только для последней версии.

## Для пользователей

Обычная установка (`bash setup.sh`) скачивает только зависимости из `requirements.txt`. Сверки, которым нужно
скачать и выполнить сторонний код, запускаются лишь по явному флагу `bash check_all.sh --network`.

Веб-версия рассчитана на запуск на своём компьютере. Не открывайте её порт в сеть и не ставьте за обратный
прокси: в ней нет ни входа по паролю, ни шифрования.
