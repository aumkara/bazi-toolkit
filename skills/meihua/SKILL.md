Мэй Хуа И Шу (梅花易数) — Нумерология Цветка Сливы. Система гадания на основе И Цзин (易经 Книга Перемен).

**Источник правды — репозиторий `bazi`**: этот файл — `skills/meihua/SKILL.md`; после `setup.sh` он подключён symlink'ами в `~/.config/opencode/skills/meihua` (OpenCode) и `~/.claude/skills/meihua` (Claude Code). Правки — в репозитории, коммитом.

## Аргументы

Skill принимает аргументы в одном из форматов:

1. `/meihua` — без аргументов: запроси вопрос и используй текущую дату/время
2. `/meihua ГГГГ-ММ-ДД ЧЧ:ММ` — расчёт по конкретной дате и времени
3. `/meihua N1 N2` — расчёт по двум произвольным числам
4. `/meihua N1 N2 N3` — расчёт по трём числам (верхняя, нижняя, изменяющаяся)
5. `/meihua вопрос` — вопрос с использованием текущего времени

Примеры:
- `/meihua 2026-04-08 14:30` — расчёт на конкретное время
- `/meihua 38 17` — два числа: верхняя триграмма из 38, нижняя из 17, изменяющаяся из суммы
- `/meihua 5 3 4` — явно задать верхнюю триграмму, нижнюю и изменяющуюся черту
- `/meihua Стоит ли менять работу?` — вопрос, время берётся текущее

Если аргументы не переданы, запроси:
1. **Вопрос** (что хочет узнать спрашивающий)
2. **Метод ввода**: дата/время, числа или текущий момент

### 1.2. Пять Стихий (五行 Wu Xing)

**Стихии триграмм:**
- Металл 金: Цянь (乾), Дуй (兑)
- Огонь 火: Ли (离)
- Дерево 木: Чжэнь (震), Сюнь (巽)
- Вода 水: Кань (坎)
- Земля 土: Гэнь (艮), Кунь (坤)

**Цикл Порождения (相生 Xiang Sheng):**
```
Дерево 木 → Огонь 火 → Земля 土 → Металл 金 → Вода 水 → Дерево 木
```
Дерево питает Огонь → Огонь создаёт Землю (пепел) → Земля рождает Металл → Металл рождает Воду (конденсация) → Вода питает Дерево

**Цикл Подавления (相克 Xiang Ke):**
```
Дерево 木 → Земля 土 → Вода 水 → Огонь 火 → Металл 金 → Дерево 木
```
Дерево пронзает Землю (корни) → Земля впитывает Воду → Вода гасит Огонь → Огонь плавит Металл → Металл рубит Дерево

### 2.1. Метод расчёта по дате и времени (时间起卦)

Для расчёта нужны:
- **Год**: номер Земной Ветви года (子=1, 丑=2, ..., 亥=12)
- **Месяц**: номер лунного месяца (1-12)
- **День**: число лунного дня (1-30)
- **Час**: номер Земной Ветви часа (子=1, 丑=2, ..., 亥=12)

**Определение Земной Ветви часа по времени:**
| Время | Ветвь | Номер |
|-------|-------|-------|
| 23:00-00:59 | 子 Zi | 1 |
| 01:00-02:59 | 丑 Chou | 2 |
| 03:00-04:59 | 寅 Yin | 3 |
| 05:00-06:59 | 卯 Mao | 4 |
| 07:00-08:59 | 辰 Chen | 5 |
| 09:00-10:59 | 巳 Si | 6 |
| 11:00-12:59 | 午 Wu | 7 |
| 13:00-14:59 | 未 Wei | 8 |
| 15:00-16:59 | 申 Shen | 9 |
| 17:00-18:59 | 酉 You | 10 |
| 19:00-20:59 | 戌 Xu | 11 |
| 21:00-22:59 | 亥 Hai | 12 |

**Определение Земной Ветви года:**
Земная Ветвь года определяется по остатку: (год - 3) mod 12. Если результат 0, то берём 12.
- Результат 1=子(Крыса), 2=丑(Бык), 3=寅(Тигр), ..., 12=亥(Свинья)
- Пример: 2026 → (2026-3) mod 12 = 2023 mod 12 = 7 → 午(Лошадь) = 7

**Определение лунной даты:**
Лунную дату и всю арифметику считает калькулятор проекта (с 2026-11-09): `"$BAZI/.venv/bin/python" "$BAZI/meihua.py" --time ГГГГ-ММ-ДД ЧЧ:ММ --json` (лунная дата — через lunar-python; если его нет — `--lunar ГОД МЕСЯЦ ДЕНЬ` явно), `--numbers N1 N2 [N3]` для чисел, `--minutes` — минутный режим (§3.5), `--month N` — лунный месяц для 卦气 при расчёте по числам. JSON отдаёт 本卦/变卦/互卦/错卦/综卦, 体/用 с отношением, 卦气 и формулы с суммами — формулы ниже нужны, чтобы ПОКАЗАТЬ расчёт человеку и проверить калькулятор глазами, не для счёта в голове.

**Формулы расчёта:**

```
Сумма_верхняя = год_ветвь + месяц_лунный + день_лунный
Сумма_полная = год_ветвь + месяц_лунный + день_лунный + час_ветвь

Верхняя триграмма (外卦) = Сумма_верхняя mod 8    (если 0, то 8)
Нижняя триграмма (内卦) = Сумма_полная mod 8      (если 0, то 8)
Изменяющаяся черта (动爻) = Сумма_полная mod 6    (если 0, то 6)
```

### 2.2. Метод расчёта по двум числам (数字起卦)

Пользователь даёт два числа N1 и N2:
```
Верхняя триграмма = N1 mod 8   (если 0, то 8)
Нижняя триграмма = N2 mod 8    (если 0, то 8)
Изменяющаяся черта = (N1 + N2) mod 6  (если 0, то 6)
```

### 2.3. Метод расчёта по трём числам

Пользователь даёт три числа N1, N2, N3:
```
Верхняя триграмма = N1 mod 8   (если 0, то 8)
Нижняя триграмма = N2 mod 8    (если 0, то 8)
Изменяющаяся черта = N3 mod 6  (если 0, то 6)
```

### 2.4. Построение гексаграммы

Гексаграмма состоит из 6 черт (爻 yao), нумеруемых снизу вверх (1=нижняя, 6=верхняя).

Верхняя триграмма (外卦) = черты 4, 5, 6 (сверху)

### 2.5. Определение Изменённой и Взаимной Гексаграмм

**Изменённая гексаграмма (变卦 Bian Gua):**
Измени одну черту (изменяющуюся) на противоположную. Пересобери верхнюю и нижнюю триграммы. Найди новую гексаграмму по таблице.

**Взаимная гексаграмма (互卦 Hu Gua):**
- Берутся черты 2, 3, 4 основной гексаграммы → новая нижняя триграмма
- Берутся черты 3, 4, 5 основной гексаграммы → новая верхняя триграмма
- Найди гексаграмму по таблице

Взаимная гексаграмма показывает скрытые процессы и промежуточный этап развития ситуации.

## ЧАСТЬ 3: АНАЛИЗ ТИ-ЮН (体用分析)

### 3.1. Определение Ти и Юн

**Ти (体)** = триграмма, в которой НЕТ изменяющейся черты. Представляет спрашивающего, субъект.
**Юн (用)** = триграмма, в которой ЕСТЬ изменяющаяся черта. Представляет ситуацию, объект, действие.

- Если изменяющаяся черта в чертах 1-3 → Юн = нижняя триграмма, Ти = верхняя
- Если изменяющаяся черта в чертах 4-6 → Юн = верхняя триграмма, Ти = нижняя

### 3.2. Анализ отношений Пяти Стихий

Определи стихию Ти и стихию Юн, затем проанализируй их взаимодействие:

| Отношение | Описание | Значение для вопроса |
|-----------|----------|----------------------|
| **Юн порождает Ти** (用生体) | Стихия Юн порождает стихию Ти | **Очень благоприятно.** Ситуация поддерживает и питает спрашивающего. Успех, приобретение, помощь извне. |
| **Ти и Юн — одна стихия** (体用比和) | Стихия Ти = стихия Юн | **Благоприятно.** Гармония, взаимопомощь, равновесие. Результат нейтрально-положительный. |
| **Ти порождает Юн** (体生用) | Стихия Ти порождает стихию Юн | **Неблагоприятно.** Спрашивающий отдаёт энергию ситуации. Потеря ресурсов, утомление, расход. |
| **Юн подавляет Ти** (用克体) | Стихия Юн подавляет стихию Ти | **Очень неблагоприятно.** Ситуация давит на спрашивающего. Опасность, потери, неудача. |
| **Ти подавляет Юн** (体克用) | Стихия Ти подавляет стихию Юн | **Условно благоприятно.** Спрашивающий может преодолеть ситуацию, но это потребует усилий. Результат достижим через труд и борьбу. |

### 3.3. Дополнительные факторы анализа

**Анализ Взаимной гексаграммы (互卦):**
- Определи стихии верхней и нижней триграмм Взаимной гексаграммы
- Оцени их отношение к стихии Ти
- Если порождают Ти — скрытая поддержка
- Если подавляют Ти — скрытые препятствия

**Анализ Изменённой гексаграммы (变卦):**
- Показывает итог, конечный результат ситуации
- Определи стихию изменённой триграммы (той, что заменила Юн)
- Оцени её отношение к Ти

**Учёт внешних триграмм (季节/时令):**
- Стихия текущего сезона/месяца может усиливать или ослаблять Ти и Юн
- Весна (1-3 лунный месяц): Дерево сильно
- Лето (4-6): Огонь силён
- Поздние сезоны по месяцам: 3,6,9,12 месяцы — Земля сильна
- Осень (7-9): Металл силён
- Зима (10-12): Вода сильна

**Сила Ти по сезону (卦气) — назвать явно** (issue #23): стихия Ти в своём сезоне — 旺 (сильна), в сезоне, который её порождает — 相 (поддержана), в сезоне, который она порождает — 休 (отдыхает), в сезоне, который она контролирует — 囚 (стеснена), в сезоне, который её контролирует — 死 (слаба). Сильный Ти переносит давление Юн; слабый Ти даже при «Юн порождает Ти» получает мало. Это уточнение к вердикту Ти-Юн, не отмена его — [интерпретация].

### 3.4. Полное поле гексаграммы: 互卦, 变卦, 错卦, 综卦 (issue #23)

Кроме Взаимной (互卦) и Изменённой (变卦) у каждой гексаграммы есть два «зеркала», которые принято смотреть, чтобы не читать образ в вакууме:
- **错卦 (цо-гуа, дополнение)** — все шесть черт инвертированы (ян ↔ инь). Показывает **обратную сторону ситуации** — то, чего в ней нет, чего не хватает или что отрицается. Пример: ䷀ 乾 ↔ ䷁ 坤.
- **综卦 (цзун-гуа, переворот)** — гексаграмма, перевёрнутая вверх ногами (порядок черт 1↔6, 2↔5, 3↔4). Показывает ситуацию **с точки зрения другой стороны** (партнёра, противника, обстоятельств). Симметричные гексаграммы (乾, 坤, 颐, 大过, 坎, 离, 中孚, 小过) при перевороте не меняются — тогда 综卦 нет, и это само по себе знак «обе стороны видят одно».

Порядок анализа: главная (本卦) → взаимная (互卦, скрытое течение) → изменённая (变卦, итог) → 错/综 (рамка: чего нет и как видит другой). 错/综 в вердикт Ти-Юн не входят — они для образа и совета, пометка [интерпретация].

### 3.5. Точность времени при расчёте по моменту (современное расширение)

Традиционный 时间起卦 берёт год (номер ветви), лунный месяц, день и **двухчасовой час (时辰)**: два вопроса в один 时辰 дают одну гексаграмму. Если пользователь задаёт второй вопрос в тот же 时辰 — предложи (а) расчёт по числам (§2.2) или (б) **режим минут/секунд**: к сумме для изменяющейся черты добавить минуты (и секунды) момента. Это осознанное современное расширение (его используют, например, скилл meihua-yishu), а не классика — в выводе так и написать: «изменяющаяся черта — с учётом минут, современное расширение». Без явного согласия пользователя — классический 时辰.

## ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Один вопрос — одно гадание.** Не перегадывай по тому же вопросу.
2. **Конкретный вопрос** даёт более точный ответ, чем абстрактный.
3. **Искренность** спрашивающего важна для качества предсказания.
4. При отсутствии конкретного вопроса можно делать общий прогноз на момент времени.
5. Если пользователь даёт только текст вопроса без чисел/даты, используй текущую дату и время.
6. Всегда показывай пошаговый расчёт, чтобы его можно было проверить.
7. В интерпретации используй богатый язык образов И Цзин — стихии, природные явления, семейные роли триграмм.
8. **Этика (issue #23).** Не гадать о здоровье и смерти (своих и чужих) как о диагнозе/сроке — только «стоит ли обратиться к врачу сейчас»; не гадать о третьих лицах без их ведома на личные темы (измена, болезнь, финансы конкретного человека) — переформулировать вопрос на самого спрашивающего («что мне делать в этой ситуации»); не гадать ради азартных ставок и не обещать выигрыш; не повторять гадание, чтобы «выпало получше». Плохой ответ сообщать прямо (правило «без подслащивания»), но всегда с одним конкретным следующим шагом из текста черты и 变卦. Гадание — инструмент размышления, а не замена решения: сказать это один раз, если человек явно перекладывает выбор на гексаграмму.
