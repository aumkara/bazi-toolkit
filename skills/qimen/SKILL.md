Ци Мэнь Дунь Цзя (奇门遁甲) — Скрытый Цзя. Система стратегической дивинации на основе 9 дворцов.

**Источник правды — репозиторий `bazi`**: этот файл — `skills/qimen/SKILL.md`; после `setup.sh` он подключён symlink'ами в `~/.config/opencode/skills/qimen` (OpenCode) и `~/.claude/skills/qimen` (Claude Code). Правки — в репозитории, коммитом.

## Аргументы

`/qimen [ГГГГ-ММ-ДД ЧЧ:ММ] [UTC+N]`

Если дата/время не указаны — используется текущий момент. Это «часовой расклад» (时家奇门).

## Порядок работы

1. Запусти калькулятор (Код и справочники — в корне репозитория `bazi` (его находят по symlink'у `~/.bazi`, который ставит `setup.sh`; другой путь — переменная `BAZI_DIR`; нет `~/.bazi` — запусти `bash setup.sh` в корне проекта). В каждом bash-блоке задавай корень явно и используй python из `.venv` (там pyswisseph; без него движки честно отказываются считать)):
```bash
BAZI="${BAZI_DIR:-$HOME/.bazi}"; PY="$BAZI/.venv/bin/python"
"$PY" "$BAZI/qimen.py" [ГГГГ-ММ-ДД ЧЧ:ММ] [UTC+N]
```

2. На основе вывода проведи интерпретацию по правилам ниже.

**Доверие к числам:** доска (局, 地盘, 天盘, 九星, 八门, 八神) с 2026-11-09 сверена с kinqimen на 300 случайных моментах — [факт]; метод 拆补 (元 по 符头 дня), пластины 转盘, записано в JSON `meta.conventions`. Доски, построенные до 2026-11-09, недостоверны (неверный 元 примерно в двух случаях из трёх и сдвиг врат) — пересчитать. Метод 置闰 (超神接气) — флаг `--method zhirun` (с 2026-11-09): 局 берётся от термина, которому принадлежит 15-дневный блок 上元-符头, 闰-блок вставляется после 芒种/大雪, когда 超神 достигает девяти дней включительно (《奇门遁甲统宗》; разница дат ≥ 8, `--zhirun-threshold 9` — чтение «实差九日»); в JSON `meta.ju_term` и `meta.chaojie` (超神/接气/正授, дней, 闰-блок). Сверено с независимой реализацией Ciallo (153/153) и с опубликованным разбором 冬至 2024 — [факт]; у kinqimen «置閏» — эвристика, не ориентир. По умолчанию — 拆补; если спрашивают про школу 置闰 — считать обеими и показать, где 局 разошлись. `meta.boundary_warnings` (термин в пределах суток, смена 时辰 в пределах 15 мин, 子-час у полуночи) — обязательны в Тени: доска на границе — считать обе и показать разницу.

## Структура карты

Доска 3×3 (九宫 Девять Дворцов) по Ло Шу:
```
┌────────┬────────┬────────┐
│ 4 巽 SE │ 9 离 S  │ 2 坤 SW │
├────────┼────────┼────────┤
│ 3 震 E  │ 5 中    │ 7 兑 W  │
├────────┼────────┼────────┤
│ 8 艮 NE │ 1 坎 N  │ 6 乾 NW │
└────────┴────────┴────────┘
```

Каждый дворец содержит 5 слоёв:
- **八神** (Дух) — наверху
- **九星** (Звезда) — небесная пластина
- **天盘干** (Ствол небесной пластины)
- **八门** (Врата) — человеческая пластина
- **地盘干** (Ствол земной пластины) — фиксированная основа

## Интерпретация

### 1. Определи вопрос и фокусный дворец
- Спрашивающий = дворец с 值符 или дворец, связанный с Десятью Божествами/стихиями вопроса
- Дело/ситуация = дворец с 值使门 (дежурные врата)
- Для конкретных тем: карьера → 开门, брак → 六合, здоровье → 天芮, путешествие → 驿马

### 2. Оцени дворец фокуса
- **Звезда** + **Врата** = основная комбинация
  - Благоприятная звезда + благоприятные врата = отлично
  - Смешанные = средне, зависит от деталей
  - Обе неблагоприятны = проблемы
- **Дух** усиливает или ослабляет
  - 值符 усиливает всё хорошее
  - 腾蛇 добавляет обман и неясность
- **Небесный ствол → Земной ствол** = отношение ситуации (небо) к основе (земля)
  - Порождение = поддержка
  - Контроль = конфликт

### 3. Специальные паттерны
- **伏吟** (небесный ствол = земной ствол в том же дворце): застой, ожидание
- **反吟** (противоположная конфигурация): разворот, возврат
- **Три Чуда в благоприятных вратах**: очень удачная ситуация
- **庚 в фокусном дворце**: препятствие, блокировка

### 4. Направления
- Благоприятное направление = дворец с лучшей комбинацией звезда+врата
- Неблагоприятное = дворец с 死门 + неблагоприятной звездой
