Джунгци (тиб. byung rtsi) — тибетская элементная астрология: знак года (животное+стихия), **Меуа** (sme ba, 1–9), **все 5 жизненных сил** и **обструктивные годы** (ло-скаг). Расчёт калькулятором + чтение простым языком. **Уверенность СРЕДНЯЯ-ВЫСОКАЯ** (2026-07-11: Лю/Лунгта/ло-скаг выверены по трём независимым линиям — Erlewine·Карма Кагью, astrotibet·Белый Берилл/ИАТТМ, Nine Ways·Бон; 300 кросс-проверок по двум 60-летним таблицам).

**Источник правды — репозиторий `bazi`**: этот файл — `skills/tibetan/SKILL.md`; после `setup.sh` он подключён symlink'ами в `~/.config/opencode/skills/tibetan` (OpenCode) и `~/.claude/skills/tibetan` (Claude Code). Правки — в репозитории, коммитом.

## Аргументы

Формат (в Claude Code — `/tibetan …`, в OpenCode — просто в сообщении): `ГГГГ-ММ-ДД`

Нужна дата (для границы года важен месяц — Лосар). Опционально прогнозный год: `--year ГГГГ` (по умолчанию — ТЕКУЩИЙ; в JSON виден в `forces_year_relation.year`). Если даты нет — спроси.

**ЧИТАЙ поля `confidence`, `not_computed`, `honesty_note`.** Что калькулятор считает и НА КАКОМ основании:

| Что | Статус | Основание / источник |
|---|---|---|
| Год-животное + стихия года | ✅ надёжно | 60-летний sexagenary (сверено с Ба Цзы) |
| **Меуа** (число 1–9, цвет, стихия) | ✅ **высокая** | якорь 1927=1, счёт назад по циклу 9; сверено по 2 независимым источникам (15 якорей, 0 противоречий). Меуа НЕ зависит от пола |
| **Срог** (жизн. сила) | ✅ высокая | = фикс. стихия животного (≥3 источника) |
| **Ла** (душа) | ✅ высокая | = мать стихии Срог (生); пример Лошадь→Дерево сходится |
| **Вангтанг** (личн. сила) | ✅ высокая | = стихия года рождения (правило явно в 2 источниках + точки Бон; поднята 2026-07-11) |
| **Лю** (тело) | ✅ **высокая** | двухшаговое правило: ключ животного × отношение стихии года к ключу (Erlewine + astrotibet, сверка 60/60 + якоря Бон; 2026-07-11) |
| **Лунгта** (конь ветра) | ✅ **высокая** | 4 триады животных → Металл/Огонь/Дерево/Вода, Земли не бывает (3 независимые линии; 2026-07-11) |
| Отношение сил к стихии года | ✅ (интерпретация) | мать/ребёнок/друг/враг/тождество по 五行; друг/враг — по Берзину |
| **Ло-скаг** (год возврата знака) | ✅ высокая | каждые 12 лет; тиб. возрасты 13/25/37/…; Берзин + Эрлевайн + Бон |
| **Дун-зур** (противоположный знак) | ✅ средняя | правило из 2 источников, термин из одного |
| **Натальная Паркха** | ❌ НЕ выдаём | нужен ВОЗРАСТ МАТЕРИ + метод школьно-расходящийся |
| Прочие «тёмные» годы (гу-мик, дур-миг…) | ❌ НЕ выдаём | правила только у одного источника (Erlewine) |

**Категорически не выдумывай то, что в `not_computed` (натальная Паркха, прочие «тёмные» годы).** Меуа и все 5 сил — вычислены и сверены, их использовать можно как [факт]. Таблица выше — справка об ОСНОВАНИЯХ; актуальный состав выданного/придержанного всегда бери из полей `confidence`/`not_computed`/`honesty_note` JSON текущего прогона (код может дорасти — JSON не устаревает, таблица может).

## Качество чтений (OVERRIDE — здесь строже обычного)

1. **Уверенность СРЕДНЯЯ-ВЫСОКАЯ — заяви честную рамку первым делом.** Онлайн-«тибетская астрология» — упрощение монастырской традиции; выданное сверено по трём независимым линиям, но глубина монастырского чтения этим не заменяется.
2. **Происхождение честно.** Это реальная древняя традиция; считаем её верхний-средний слой. Полная Паркха и тонкие гороскопы препятствий по печатным таблицам (Cornu/Men-Tsee-Khang) — к специалисту.
3. **Только посчитанное.** Меуа и все 5 сил, ло-скаг/дун-зур — используй. Про натальную Паркху и прочие «тёмные» годы — объясни, ЧТО это и почему не посчитано, но **НЕ давай выдуманных значений**.
4. **Граница года = Лосар, и он РЕЗОЛВИТСЯ кодом** (2026-07-15): точные даты Лосара (Пхугпа — ЦТА/Далай-лама, таблица 1900–2100, выверена печатно+анонсами) зашиты в tibetan.py; блок `losar` в JSON даёт дату, `birth_relative` (до/в день/после) и `date_confidence` (упомяни, если `computed-only` — рождения до 1927). Год и Меуа в основном выводе УЖЕ правильные. `losar_warning` появляется только на краях (рождение в сам день Лосара — тибетские сутки с рассвета; годы расхождения школ Пхугпа↔Цурпху; год вне таблицы) — тогда веди оба варианта из `alt_if_before_losar`, причина в тексте предупреждения.
5. **Совпадение с Ба Цзы — не независимое подтверждение.** Знак года в обеих системах из одного календарного корня, но границы разные: Ба Цзы режет год по Личуню, Джунгци — по Лосару; у рождённых между ними знаки законно РАЗНЫЕ (это два календаря, не ошибка). Скажи это.
6. **Без подслащивания.** У стихии, животного, Меуа, каждой силы — теневая сторона; называй.
7. **Обязательные секции:** Тень + маркеры [факт]/[интерпретация]/[спекуляция].

## Что в JSON (как читать)

- `year_sign`: `animal`, `year_element`, `full` (напр. «Земля Змея»), `animal_quality`, `element_quality`, `animal_fixed_element`.
- `mewa`: `number` (1–9), `color`, `element`, `confidence`, `meaning` (темы = пересечение 5 источников + `disagreements` — где источники спорят: транслируй темы ИЗ JSON, расхождения называй честно, не выбирай молча; статус [интерпретация]), `alt_if_before_losar` (только у краевых случаев Лосара).
- `forces`: ВСЕ 5 сил, у каждой `element` + `basis` + `confidence` (Срог, Лю, Вангтанг, Лунгта, Ла).
- `forces_year_relation`: для прогнозного года — `year_sign`, `year_element` и `relations` (по каждой силе: `relation` мать/ребёнок/друг/враг/тождество + `reading`).
- `obstacle_year`: `forecast_year`, `status` (null | ло-скаг | дун-зур с `confidence` и `reading`), `info` (правило и тибетские возрасты).
- `losar`: `date` (фактический Лосар года рождения, Пхугпа), `tsurphu_date` (если школа Карма Кагью даёт другую), `birth_relative`, `year_used`, `date_confidence`, `note`.
- `alt_if_before_losar` (только на краях: день Лосара / школы расходятся / год вне таблицы 1900–2100): полный второй вариант — `year_sign`, `mewa`, `forces`, `forces_year_relation`, `obstacle_year`, `note` с причиной.
- `parkha`: `natal_value: null`, `frame` (8 триграмм со стихиями — каркас), `withheld_reason`.
- `losar_warning` (null, если год резолвится однозначно), `not_computed`, `confidence`, `honesty_note`.

## Формат вывода (.md, простым языком)

Заголовок: `# Джунгци (тибетская элементная астрология) простыми словами` + `### дата`.

Секции:
1. **Честное предупреждение** (первым) — уверенность средняя; что считаем, что честно не выдаём и почему; это не глубокое монастырское чтение.
2. **Твой знак года** — стихия + животное: сочетание, сильная и теневая сторона. Основная часть.
3. **Меуа** — число, цвет, стихия: что это за «родовое число» (по традиции связано с защитным божеством и жизненными испытаниями — но конкретику без источника не выдумывай), его смысл и теневая сторона. [факт] число; [интерпретация] смысл.
4. **5 сил жизни** — назови все 5, их смысл и вычисленную стихию каждой (Срог — витальность, Лю — тело/здоровье, Вангтанг — личная сила/реализация, Лунгта — конь ветра/удача, Ла — душа/защита). У каждой — и сильная, и теневая сторона.
5. **Силы и {прогнозный год}** — из `forces_year_relation`: как стихия года относится к каждой силе (питает/истощает/давит/тождество). Плюс `obstacle_year`: если прогнозный год — ло-скаг (возврат знака) или дун-зур (противоположный) — скажи прямо с его `confidence`; если нет — одной строкой «в год препятствий не попадает» и когда ближайший ло-скаг. Аккуратно, [интерпретация], не обещание.
6. **Паркха** — кратко объясни 8 триграмм (каркас есть в JSON), и честно: твоя натальная триграмма НЕ вычислена — нужен возраст матери; методы расходятся.
7. **Тень** — рамка уверенности; натальная Паркха и прочие «тёмные» годы не выданы; Лосар: дата из таблицы (+ `date_confidence`; края — оба варианта); совпадение с Ба Цзы не независимо. Маркеры [факт]/[интерпретация]/[спекуляция]. Обязательно.
