Джйотиш (ведическая астрология) — карта по сидерическому зодиаку: Лагна, планеты по домам, накшатра Луны, периоды-даши. Расчёт калькулятором + чтение простым языком.

**Источник правды — репозиторий `bazi`**: этот файл — `skills/jyotish/SKILL.md`; после `setup.sh` он подключён symlink'ами в `~/.config/opencode/skills/jyotish` (OpenCode) и `~/.claude/skills/jyotish` (Claude Code). Правки — в репозитории, коммитом.

## Аргументы

Формат (в Claude Code — `/jyotish …`, в OpenCode — просто в сообщении): `ГГГГ-ММ-ДД ЧЧ:ММ М|Ж [город|UTC+N]`

Джйотиш для асцендента (Лагны) и домов требует **место рождения (широту/долготу) И точное время**. Если города нет в базе — спроси координаты, не подставляй выдуманные. Без точного времени — Лагна и дома ненадёжны, скажи прямо.

## Вспомогательные файлы

Код и справочники — в корне репозитория `bazi` (его находят по symlink'у `~/.bazi`, который ставит `setup.sh`; другой путь — переменная `BAZI_DIR`; нет `~/.bazi` — запусти `bash setup.sh` в корне проекта). В каждом bash-блоке задавай корень явно и используй python из `.venv` (там pyswisseph; без него движки честно отказываются считать):

```bash
BAZI="${BAZI_DIR:-$HOME/.bazi}"   # корень checkout'а; переопределяй в каждом bash-блоке
PY="$BAZI/.venv/bin/python"
```
 **Считай калькулятором** (нужны широта/долгота — резолвятся из города):

```bash
# координаты + UTC-смещение города:
"$PY" -c "import sys; sys.path.insert(0,'$BAZI'); from geo import resolve; from timezones import historical_utc_offset; lat,lon=resolve('Москва'); print(lat,lon, historical_utc_offset('Москва',1990,5,15))"
# расчёт: jyotish.py ДАТА ВРЕМЯ ШИРОТА ДОЛГОТА +СМЕЩЕНИЕ --json
"$PY" "$BAZI/jyotish.py" 1990-05-15 14:30 55.75 37.62 +4 --json
"$PY" "$BAZI/jyotish.py" --test
```

Долготы планет сидерические, выверены (тождество сидерика=тропик−аянамша, двойной движок). **Положения, накшатры, даши — [факт].**

Гайд еды и чая — файл проекта `ahara.md` (ахара): вкусы грах, дана/пост, доша-слой, слои «по жизни / напряжение / возраст». Прочитай при составлении секции «Еда и чай».

Гайд дня — файл проекта `dinacharya.md` (дина-чарья): движение (вьяяма) по доша-уклону, сон, утренний уклад, дни недели/цвета/металлы, камни-справка. Прочитай при составлении секции «День за днём».

## Язык вывода

Русский, простыми словами. Санскрит давай в скобках при первом упоминании: «Лагна (восходящий знак)», «накшатра (лунная стоянка)», «даша (планетный период)». Дальше — по-русски.

## Качество чтений (OVERRIDE)

1. **Без подслащивания.** Сложные положения (планета в дебилитации, тяжёлая даша Сатурна/Раху/Кету, поражённый дом) — называй прямо. «Сейчас период испытаний» лучше, чем ложный оптимизм.
2. **Конвенции честно (важно).** Расчёт на: **аянамша Лахири + знаковые дома (whole-sign) + Вимшоттари + средний узел**. Другие школы (Раман/KP, Плацидус, истинный узел) дадут иное. Скажи это — результат зависит от выбора.
3. **Не выдумывать классику.** Не цитируй БПХШ/Джаймини конкретными шлоками без уверенности. «Традиционно считается», «по логике школы».
4. **Йоги — не полно.** Калькулятор ловит лишь несколько базовых йог (`yogas` + поле `note`). Не делай вид, что это полный йога-анализ; скажи, что варги (дробные карты) и большинство йог за рамками.
5. **Даша = окно, не приговор.** Маха/антар-даша задаёт ТЕМУ периода, а не событие.
6. **Обязательные секции:** Тень + маркеры [факт]/[интерпретация]/[спекуляция].

## Что в JSON (как читать)

- `lagna` — восходящий знак (раши), задаёт «я», тело, точку отсчёта домов.
- `moon_nakshatra` — накшатра Луны (+пада, +управитель): в Джйотише Луна важнее Солнца — это ум и эмоции; накшатра тонко описывает натуру.
- `grahas` — 9 планет: `rashi`(знак), `house`(дом 1-12 от Лагны), `nakshatra`, `retrograde`. Дома: 1 я/тело, 2 деньги/семья/речь, 3 усилия/братья, 4 дом/мать/счастье, 5 дети/творчество/удача, 6 враги/болезни/долги, 7 партнёр/брак, 8 кризисы/трансформация/наследство, 9 удача/учитель/дхарма, 10 карьера/статус, 11 доходы/друзья, 12 потери/затворничество/освобождение.
- `maha_dasha` + `antar_dasha` — планетный период на дату из поля `dasha_as_of` (по умолчанию — момент запуска): ЧЬЯ энергия сейчас разворачивается.
- `yogas` — несколько базовых сочетаний.
- `tropical` — «западный взгляд»: тропические Солнце/Луна/асцендент (знак + градус). Это ТЕ ЖЕ планеты в тот же момент, только круг отсчитан от равноденствия, а не от звёзд (`shift_deg` = аянамша) — НЕ отдельная система и НЕ новая информация, мостик к привычному «я Близнецы». `near_cusp=true` — точка у самой границы знака (скажи об этом прямо: «на грани двух знаков»).

## Формат вывода (.md, простым языком)

Заголовок: `# Джйотиш простыми словами` + `### дата, время, город, пол`.

Секции:
1. **Как это читать** — это сидерическая (звёздная) система, отличается от привычной западной; конвенции названы; даши = темы периодов.
2. **Кто ты по сути** — Лагна + Луна (накшатра): как ты выглядишь для мира и какой у тебя внутренний эмоциональный склад. Простыми словами.
3. **Расклад жизни по домам** — пройди по ключевым планетам/домам: где сила, где напряжение. Не перечисляй сухо — свяжи с реальными темами (дом/семья, дело, партнёр, здоровье).
4. **Йоги** — 1–2 заметных сочетания, что дают, с тенью. Оговори неполноту.
5. **Деньги/дело, Отношения, Здоровье** — что говорят дома 2/10/11, 7, 6/8.
6. **Период жизни и текущий год** — текущая маха/антар-даша: тема этих лет; что активно в текущем году (дата расчёта — `dasha_as_of`; если даша/антар меняется в этом году — отметь). Окно и риск, не обещание.
7. **Еда и чай** — по файлу проекта `ahara.md`: опорная еда — вкус/продукты управителя Лагны (`house_lords[0].lord`); падших благодетелей поддержать на столе, тяжёлых вредителей — дана/пост, НЕ тарелка; 2-й дом = пищевые привычки; чай по доша-уклону только с пометкой «похоже на уклон — проверь по телу» (пракрити канонично определяет осмотр, не карта — [спекуляция]). Лагна у границы знака (`lagna.degree % 30` <1 или >29) → две версии опорной еды. Одной строкой: не медицина.
8. **День за днём** — по файлу проекта `dinacharya.md`: движение — классическая мера «до половины силы» + ТОТ ЖЕ доша-уклон, что в еде (не пересобирать), Марс как окраска; сон — раньше и регулярнее, дневной — исключения, 12-й дом/Луна — окраска [интерпретация]; опорные дни недели благодетелей и «день тишины» владыки тяжёлой даши, цвет дня — игровой слой; камни НЕ назначать (справка о традиции + «к живому специалисту»); хора/рахукалам — честно «за рамками» (ежедневный пересчёт). Одной строкой: не медицина.
9. **Западный взгляд** (короткий подраздел из поля `tropical`, перед Тенью) — тропические Солнце/Луна/асцендент: «в привычном западном гороскопе ты — <знак Солнца>, асцендент <знак>». Обязательно объясни сдвиг: это те же планеты, но другой отсчёт круга, поэтому знаки выше в файле другие; НЕ отдельная система, НЕ дополнительное подтверждение — просто перевод на знакомый язык. `near_cusp` → «на самой границе знаков X/Y». Домов, аспектов и прогнозов западной школы тут НЕТ — не досочиняй их.
10. **Тень** — тяжёлые места карты, что сгладил, зависимость от выбора конвенций, неполнота йог/варг. Маркеры [факт]/[интерпретация]/[спекуляция]. Обязательно.
