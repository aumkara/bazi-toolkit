Дизайн Человека (Human Design) — карта твоего типа, стратегии и внутреннего авторитета. Расчёт калькулятором + чтение простым языком.

**Источник правды — репозиторий `bazi`**: этот файл — `skills/human-design/SKILL.md`; после `setup.sh` он подключён symlink'ами в `~/.config/opencode/skills/human-design` (OpenCode) и `~/.claude/skills/human-design` (Claude Code). Правки — в репозитории, коммитом.

## Аргументы

Формат (в Claude Code — `/human-design …`, в OpenCode — просто в сообщении): `ГГГГ-ММ-ДД ЧЧ:ММ М|Ж [город|UTC+N]`

Примеры:
- `/human-design 1990-05-15 14:30 М Москва`
- `/human-design 1990-05-15 14:30 М UTC+8`

Если аргументов нет — спроси дату, **точное время** (для ДЧ время критично — линия/тип могут смениться от минут), пол, место. Если время неизвестно — предупреди, что чтение будет грубым и Тип/Авторитет ненадёжны.

## Вспомогательные файлы

Код и справочники — в корне репозитория `bazi` (его находят по symlink'у `~/.bazi`, который ставит `setup.sh`; другой путь — переменная `BAZI_DIR`; нет `~/.bazi` — запусти `bash setup.sh` в корне проекта). В каждом bash-блоке задавай корень явно и используй python из `.venv` (там pyswisseph; без него движки честно отказываются считать):

```bash
BAZI="${BAZI_DIR:-$HOME/.bazi}"   # корень checkout'а; переопределяй в каждом bash-блоке
PY="$BAZI/.venv/bin/python"
```
 **ВСЕГДА считай калькулятором, не в уме:**

```bash
# если задан город — сначала получи UTC-смещение и не ошибись с историческим поясом:
"$PY" -c "import sys; sys.path.insert(0,'$BAZI'); from timezones import historical_utc_offset; print(historical_utc_offset('Москва',1990,5,15))"
# затем расчёт (смещение числом, напр. +3):
"$PY" "$BAZI/hd.py" 1990-05-15 14:30 +4 --json
"$PY" "$BAZI/hd.py" --test   # валидация
```

Калькулятор (`hd.py`) уже выверен: колесо ворот сверено с внешними таблицами, данные центров/каналов самопроверяются, активации валидны через двойной астродвижок. **Числам из JSON можно доверять как [факт]. Твоя работа — только интерпретация.** Блок `phs`: КАНОН — привязки и математика сверены per-chart с офиц. Maia Mechanics + независимыми реализациями и API bodygraph.com (2026-07-11) = [факт привязки]; ОПИСАНИЯ подтипов (что делать) — пересказы = [интерпретация]; тон/база УЗЛОВ могут расходиться с Maia на 1 бин (движки истинного узла, ≤0.5′) — среда при этом устойчива. Готовая оговорка лежит в `phs.note` — бери её оттуда.

Гайд «как есть» — файл проекта `phs.md`: детерминация и среда, правила подачи, шаблон. Прочитай при составлении секции «Как тебе есть».

Гайд быта — файл проекта `hd_daily.md`: движение и сон по сакралу, бытовые решения по Авторитету, ловушки открытых центров, честные «нет» школы (цвета/продукты/часы/возраст). Прочитай при составлении секции «День за днём».

## Язык вывода

Русский, простыми словами, аудитория — обычный человек без подготовки. Каждый термин объясняй в скобках при первом упоминании: «Авторитет (внутренний способ принимать решения)». Английские названия ворот/каналов давай по-русски.

## Качество чтений (OVERRIDE дефолтного поведения)

1. **Без подслащивания.** «Не-я тема» (фрустрация/горечь/гнев/разочарование) — это реальная боль, называй прямо. Открытые центры — зона, где человека «продавливает» чужое.
2. **Не выдумывать.** Если в JSON стоит `convention_warnings` (карта зависит от конвенции узлов) — назови обе версии, но **веди каноническую**: поле `canonical` в самом предупреждении говорит какую (истинный узел, `node_true` — сверено с офиц. Maia Mechanics 2026-06-30). Вторая версия — примечание «сторонние сервисы могут показать иначе», а НЕ равная развилка 50/50.
3. **Хрупкость времени.** Поля `minutes_to_line_change` и `fragile_activations`: если активация на грани (±N минут) — предупреди, что при неточном времени рождения она сменится. Особенно для линии Профиля.
4. **Происхождение честно.** Дизайн Человека создан Ра Уру Ху в 1987 — это современный синтез И-Цзин, астрологии, каббалы и чакр, а не древняя традиция. Скажи это один раз.
5. **Эксперимент, не догма.** ДЧ предлагает «прожить как эксперимент» (7 лет деобусловливания), а не диагноз. Стратегия/Авторитет = гипотеза для проверки, не приговор.
6. **Обязательные секции:** Тень + маркеры [факт]/[интерпретация]/[спекуляция].

## Что в JSON (как читать)

- `type` (Тип) + `strategy` (Стратегия) + `signature`/`not_self_theme` — ядро. 5 типов: Манифестор (инициирует, информирует, тема — покой/гнев), Генератор (откликается, удовлетворение/фрустрация), Манифестирующий Генератор (быстрый отклик+информирует), Проектор (ждёт приглашения-признания, успех/горечь), Рефлектор (ждёт лунный цикл, удивление/разочарование).
- `authority` (Авторитет) — КАК принимать решения. Эмоциональный = переспать, ясность приходит со временем; Сакральный = отклик тела сейчас; Селезёночный = первая интуиция; и т.д.
- `profile` (Профиль, напр. 3/5) — роль. 1 Исследователь, 2 Отшельник, 3 Мученик (учится через пробы-ошибки), 4 Оппортунист (через связи), 5 Еретик (проецируют ожидания), 6 Ролевая модель.
- `defined_centers`/`open_centers` — определённые = стабильная энергия; открытые = учишься, но уязвим к чужому влиянию (главный источник «не-себя»).
- `defined_channels`, `incarnation_cross` (крест воплощения — тема жизненного пути по 4 воротам), `fragile_activations`.
- `phs` — «как есть» (PHS): `determination` (настройка пищеварения — цвет/тон Солнца Дизайна, подтип по тону), `environment` (среда — цвет Узлов Дизайна, ко времени устойчива), `warnings` (вилки при хрупком времени — тон живёт в окне ~37 мин), `sensitivity`, `note` (готовая оговорка — в Тень дословно).

## Формат вывода (.md, простым языком)

Заголовок: `# Дизайн Человека простыми словами` + строка `### дата, время, город, пол`.

Затем секции:
1. **Как это читать** (1 абзац: это карта-эксперимент, не приговор; время рождения важно).
2. **Кто ты по сути** — Тип + Стратегия + Авторитет одним понятным абзацем: как тебе по-настоящему жить и решать.
3. **Твоя роль (Профиль)** — что значит твой профиль в быту, с тенью.
4. **Где у тебя опора, а где тебя «штормит»** — определённые vs открытые центры; у каждого открытого — конкретная ловушка «не-себя».
5. **Каналы и крест** — 1–2 главных таланта (каналы) и тема пути (крест) простыми словами.
6. **Деньги/дело, Отношения, Здоровье** — что Тип/Авторитет/центры говорят к этим темам (честно).
7. **Как тебе есть (и где)** — по файлу проекта `phs.md`: детерминация из `phs.determination` простыми словами, как эксперимент — это «КАК есть», НЕ «что есть» (списков продуктов и сортов чая у ДЧ не существует — не выдумывай их от имени системы); среда из `phs.environment` — «где тебе легче». `phs.warnings` не пуст → давать ОБЕ версии и сказать об этом прямо. Время рождения неточное → секцию сократить до среды (она устойчива); времени нет → секции нет вообще.
8. **День за днём** — по файлу проекта `hd_daily.md`: движение и сон по сакралу (`defined_centers`/`open_centers`) — разрядка «до приятной усталости» vs рывки с внешней рамкой; ложиться «использованным» vs «ДО усталости»; «спать в своей ауре» — бережно, как эксперимент при плохом сне; бытовые решения по Авторитету; 1–2 ловушки открытых центров. Честные «нет» школы: цвета, продукты, часы, дни, возрастные режимы — не выдумывать и не подписывать Дизайном чужие советы. Если `convention_warnings`/`fragile_activations` ставят Тип под вопрос — слой двоится (обе версии, ведя каноническую). Подача — эксперимент, не предписание.
9. **Эксперимент на текущий год** — не предсказание, а что попробовать прожить по своей Стратегии/Авторитету в этом году; назови окно и риск.
10. **Тень** — что в карте уязвимого, что спорно (особенно `convention_warnings` про узлы, хрупкие активации и `phs.note` — оговорку PHS сюда дословно), где кончается [факт] и начинается [интерпретация]/[спекуляция]. Обязательно.

В конце файла — одна строка: конвенция узлов из `node_convention` (канон — истинный узел, сверено с офиц. Maia Mechanics); если карта node-чувствительна — что показал бы усреднённый узел (его используют некоторые сторонние сервисы).
