Совместимость двух людей по трём независимым системам — Ба Цзы (合婚), Джйотиш (Аштакута) и Дизайн Человека. На выходе **один файл `совместимость.md` + его PDF**, простым языком: где легче, где труднее, по-разному для A и B. **НЕ единый процент, НЕ приговор «вам можно/нельзя».**

**Источник правды — репозиторий `bazi`**: этот файл — `skills/profile3-compare/SKILL.md`; после `setup.sh` он подключён symlink'ами в `~/.config/opencode/skills/profile3-compare` (OpenCode) и `~/.claude/skills/profile3-compare` (Claude Code). Правки — в репозитории, коммитом.

*Выверен против кода живьём: **2026-07-01** (CLI, ключи JSON, compat.py, гейты); 2026-07-11 — деперсонализация (**в тексте скилла НЕТ ничьих дат/времён/мест рождения — и не добавляй**, примеры только плейсхолдерами), политика «без времени — не считаем», ссылки переведены на /profile3 (/profile6 удалён), штамп версии движков `_engines.sha` при персисте, скилл переименован `/profile6-compare` → `/profile3-compare`; 2026-07-11 (время): исторические оффсеты → IANA tzdb + городские окна МСК+1 (`CUSTOM_CITY_PERIODS`), шаблоны оффсетов без приклеенного плюса (отрицательные Нью-Йорк −5 и дробные Сеул +8.5 законны), канал `NOTE` с «⚠» → обязательная оговорка чтения, добавление города = `CITIES`+`geo.LAT`+`CITY_IANA`. Свод самопроверок кода — `bash "$DIR/check_all.sh"`. Правишь контракт кода (CLI / ключи / оговорки) — в том же заходе правь скилл и обнови эту дату.*

Это надстройка над `compat.py` (движок) и зеркало профиля `/profile3` на двоих (та же тройка систем). Сравниваются ТОЛЬКО 3 системы (решение проекта): Матрица/Джунгци/Генные Ключи в сравнение НЕ идут (нет канонического метода на двоих / дублируют корень / мягкая авторская система).

## Аргументы

Два человека, по одному на строку, + тип связи:
```
/profile3-compare
A  ГГГГ-ММ-ДД ЧЧ:ММ М|Ж Город
B  ГГГГ-ММ-ДД ЧЧ:ММ М|Ж Город
--rel=романтика|деловые|дружба|семья      # по умолчанию романтика
```
`--rel` важен: Аштакута и Хэ Хунь — БРАЧНЫЕ системы. Для не-романтической связи числа считаются, но `compat.py` сам кладёт оговорку в `meta.marriage_systems_note` (при романтике поле = null) — транслируй её из JSON в текст, не прячь и не пересказывай по памяти.

## КРИТИЧЕСКОЕ перед расчётом (та же ловушка, что в /profile3, удвоенная)

Подтверди вслух для КАЖДОГО из двоих по отдельности: **чьи данные, точную дату и ВРЕМЯ (минуты, AM/PM), пол, город/пояс.** Реальный случай: тихая подмена чужих времени и пола перевернула Лагну/Тип/Авторитет. На двоих риск удваивается — НЕ дай данным одного протечь в другого.

- **Сверяй по дате/ВРЕМЕНИ/полу/оффсету — НЕ по имени папки.** Папка профиля названа лишь датой+городом; время и пол в имени НЕ закодированы.
- Чего не хватает (время/пол/город) — **спроси**, не подставляй. **Нет времени рождения хотя бы одного из двоих — сравнение НЕ считаем и ничего не придумываем** (ни полудня, ни прикидок): Луна/Лагна и Тип/Авторитет без времени — гадание, направленные сигналы могут развернуться. Предложи добыть время или ректификацию.
- **Ничего не сохраняй** про людей (ни `user.yaml`, ни память) — только вывод-результат можно (см. «Куда сохранять»). Данные людей не оседают.
- Если время «около/примерно» — Лагна и каналы плывут; `compat.py` сам помечает хрупкость к времени (`jyotish.time_fragility` в его JSON), вынеси это в Тень синтеза, при сильной хрупкости предложи ректификацию.

## Что делает

1. Считает ЗАНОВО 3 JSON на каждого (Ба Цзы, Джйотиш, Дизайн Человека) — дёшево, детерминировано, текущая версия калькуляторов.
2. Гоняет `compat.py` → структурный дайджест «легче / труднее / по-разному для A и B» (не складывает числа разных систем).
3. Агент-синтез превращает дайджест в прозу простым языком (как `4_synthesis` в /profile3, те же правила честности).
4. Собирает PDF.

Готовые `.md`-профили каждого человека (если уже посчитаны в `profiles/<дата>_<город>/`) — переиспользуются как КОНТЕКСТ агенту-синтезу (богаче портрет), но число сравнения всегда из свежего JSON. Если профиля нет — синтез работает по одному дайджесту (полно, просто меньше индивидуального колорита). **Эта команда НЕ генерирует недостающий /profile3** — это отдельный запуск.

## Шаг 1. Разобрать обоих + резолвить места

`DIR="${BAZI_DIR:-$HOME/.bazi}"` (код; `~/.bazi` — symlink на корень проекта, его ставит `setup.sh`). Для КАЖДОГО человека получи смещение UTC (исторически верное!) и координаты КОДОМ — не в уме:

```bash
DIR="${BAZI_DIR:-$HOME/.bazi}"
python3 -c "import sys; sys.path.insert(0,'$DIR')
from timezones import historical_utc_offset; from geo import resolve
for tag,(c,y,m,d) in {'A':('ГОРОД_A',ГОД,МЕС,ДЕНЬ),'B':('ГОРОД_B',ГОД,МЕС,ДЕНЬ)}.items():   # подставь данные из запроса
    off,note=historical_utc_offset(c,y,m,d); lat,lon=resolve(c)
    print(f'{tag} OFFSET={off} LAT={lat} LON={lon} NOTE={note}')"
```

Оффсеты исторически честные (зарубежные и постсоветские — IANA tzdb с летним временем; советская эпоха — городские окна МСК+1); бывают **отрицательные** (Нью-Йорк −5) и **дробные** (Сеул до 1961 +8.5) — калькуляторы понимают, знак/точку не «чини». **`NOTE` с «⚠»** (перевод часов в день рождения, оккупация, спорный переход области, Донецк-2014, LMT) — обязательная оговорка чтения: в Тень и, если меняет карту, в синтез.
Город не в базе → `resolve` бросит ошибку; НЕ подставлять координаты молча. Добавление города (данные из проверяемого источника; сообщи пользователю): `timezones.CITIES` + `geo.LAT` + `timezones.CITY_IANA` (зона IANA — источник исторических оффсетов); `CITY_BASE_TZ`/`CUSTOM_CITY_PERIODS` НЕ трогай. Проверяемых данных нет → спроси, не выдумывай.

Запомни `OFFSET_A/LAT_A/LON_A/NOTE_A` и `OFFSET_B/LAT_B/LON_B/NOTE_B` (у двоих они РАЗНЫЕ, если города/даты разные — не переноси оффсет одного на другого).

## Шаг 2. Посчитать 3 JSON на каждого + проверка

Изоляция обязательна: свой `RUN_ID`/`$TMP`, все JSON туда, ВСЕ калькуляторы — ОДНИМ bash-блоком (переменные шелла не живут между вызовами Bash). Астрономия идёт через swisseph из `.venv` (файлы-скрипты бутстрапятся сами); пустой `errs.log` ⇒ swisseph отработал. Сообщение «pyswisseph не установлен — расчёт остановлен» = ОТКАЗ, чинить установкой в `.venv`, не «интерпретировать сломанное».

⚠️ Ба Цзы переводит время в ИСТИННОЕ СОЛНЕЧНОЕ: поле `input.time` в его JSON будет отличаться от поданного (поправка на долготу) — это НЕ ошибка.

```bash
export PYTHONDONTWRITEBYTECODE=1
DIR="${BAZI_DIR:-$HOME/.bazi}"
SCRATCH="<scratchpad-папка этой сессии>"          # из системного промпта (запасной: ${TMPDIR:-/tmp})
RUN_ID=$(uuidgen); TMP="$SCRATCH/compat/$RUN_ID"; mkdir -p "$TMP"; echo "TMP=$TMP"

# подставь OFFSET/LAT/LON КАЖДОГО из Шага 1 (НЕ хардкодь). Пол — М|Ж как подтверждено.
# $OFF_* подставляется КАК ЕСТЬ, со знаком: 3 → UTC3/3, -5 → UTC-5/-5, дробный 8.5 законен; плюс не приклеивай.
E="$TMP/errs.log"                 # stderr калькуляторов; пустой ⇒ swisseph отработал чисто
python3 "$DIR/bazi.py"    ДАТА_A ВРЕМЯ_A ПОЛ_A UTC$OFF_A --city ГОРОД_A --json > "$TMP/A_bazi.json"    2>>"$E"
python3 "$DIR/jyotish.py" ДАТА_A ВРЕМЯ_A $LAT_A $LON_A $OFF_A --json            > "$TMP/A_jyotish.json" 2>>"$E"
python3 "$DIR/hd.py"      ДАТА_A ВРЕМЯ_A $OFF_A --json                          > "$TMP/A_hd.json"      2>>"$E"
python3 "$DIR/bazi.py"    ДАТА_B ВРЕМЯ_B ПОЛ_B UTC$OFF_B --city ГОРОД_B --json > "$TMP/B_bazi.json"    2>>"$E"
python3 "$DIR/jyotish.py" ДАТА_B ВРЕМЯ_B $LAT_B $LON_B $OFF_B --json            > "$TMP/B_jyotish.json" 2>>"$E"
python3 "$DIR/hd.py"      ДАТА_B ВРЕМЯ_B $OFF_B --json                          > "$TMP/B_hd.json"      2>>"$E"
python3 "$DIR/verify_all.py"      # health-проверка (swisseph, конвенция узлов); фикстура, НЕ карта
cat "$E"                          # пусто ⇒ ок; иначе покажи и почини ДО интерпретации
```

`verify_all.py` — общий health-чек (на встроенной фикстуре, не на этих людях). FAIL → не интерпретируй сломанное, скажи, что починить. Пол в JSON берётся из ввода Ба Цзы (`input.gender`) → именно он задаёт роли жених/невеста в Аштакуте; перепутаешь пол — перевернёшь направленные куты.

## Шаг 3. Запустить compat.py → дайджест

```bash
python3 "$DIR/compat.py" "$TMP/A_bazi.json" "$TMP/A_jyotish.json" "$TMP/A_hd.json" \
                         "$TMP/B_bazi.json" "$TMP/B_jyotish.json" "$TMP/B_hd.json" \
                         --rel=РЕЛ --json > "$TMP/compat.json"
```
Порядок путей строгий: A_bazi A_jyotish A_hd B_bazi B_jyotish B_hd. `compat.json` — это вход агента-синтеза. Бегло глянь дайджест (`ease_friction.ease/friction/directional`, `bazi.total`, `jyotish.total_display`, `jyotish.mangal_signal.note_verdict`, `human_design.*`), чтобы поймать явный сбой до синтеза.

## Шаг 4. (опц.) Найти готовые профили как контекст

Для каждого человека глянь `"$DIR/profiles/<дата>_<город>/"` (и `…__3sys/`) — если там есть профиль (4-файловый /profile3 или старый 7-файловый), это его индивидуальный контекст для синтеза. **Перед переиспользованием убедись, что это ТОТ человек** (дата+ВРЕМЯ+пол совпали — имя папки несёт лишь дату+город). Сомневаешься — не переиспользуй; свежий `compat.json` всё равно авторитетен для сравнения. Контекст каждого держи помеченным «это про A» / «это про B» — не смешивай.

## Шаг 5. Агент-синтез → `совместимость.md`

Отдельным субагентом (чистый контекст). Дай ему: путь `compat.json`; данные рождения A и B и тип связи; (опц.) пути к готовым `.md` каждого с пометкой чьи; путь сохранения `$OUT/совместимость.md`.

⚠️ **Модель субагентов = модель сессии.** Синтез (этот шаг) и верификатор Шага 5.6 запускаются БЕЗ параметра `model` — наследуют модель основной сессии; занижать до haiku/sonnet нельзя, включая разовые проверочные вызовы (правило профильных скиллов от 2026-07-10 действует и здесь); PreToolUse-хук `deny-model-downgrade.py` такое блокирует. Единственный допустимый явный override — `opus`, и только как фолбэк, если fable отказывается.

**Задача агента — проза простым языком из дайджеста. Правила честности — как у синтеза профиля (`4_synthesis.md`), но про ДВОИХ:**

- **НИ ОДНОГО иероглифа, НИ ОДНОГО системного номера, НИ ОДНОГО спец-термина** (даже русскими буквами: Лагна, накшатра, кута, граха, раши, экзальтация, Мангал, седьмой дом/сектор брака, управитель, наложение домов, аспект/дришти, сожжённый/ретроградный Марс, 用神, столп, ворота, канал, Генератор, авторитет — всё → смысл обычными словами). Смысл бери из `detail`-строк `compat.json` и из файлов 1–6, НЕ выдумывай. Названия систем (Ба Цзы, Джйотиш, Дизайн Человека), планет, стихий, знаков, год/возраст и маркеры [факт]/[интерпретация]/[спекуляция] — остаются.
- **Транслируй honesty-поля `compat.json` как есть** — их содержимое живёт в JSON, не в скилле (JSON пересчитывается каждый прогон и не устаревает): `meta.note`/`independence`/`framing`/`marriage_systems_note`, `jyotish.marriage_caveat`/`school_note`/`confidence`/`time_fragility`, note-поля `bazi`/`human_design`. Что из этого — в «Как читать», что — в Тень, реши по смыслу, но потерять нельзя ничего.
- **НЕ единый процент.** Не складывай 6.5/10 и 11.5/36 в «итог». Это три разных языка о разных слоях. Числа демотированы в детали; ведёт проза.
- **Рамка: окна и напряжение, НЕ приговор.** Не «вам подходит/не подходит», а «здесь легко само, здесь придётся тратить силы».
- **Направленность = «по-разному для A и B».** Где сигнал несимметричен (кто кого тянет/перекрашивает, кто «ниже» в куте) — назови, кто именно и в какую сторону. Не усредняй в «у вас».
- **Кросс-системная сходимость — главный сигнал, но взвешивай независимость.** Если ≥2 НЕЗАВИСИМЫХ языка сходятся — это вес. Но Ба Цзы и Джйотиш частично делят элементно-цикловой корень → их согласие менее независимо, чем когда к ним присоединяется Дизайн Человека (другая логика). Подписывай «сошлись традиции», а не «доказано».
- **Где системы РАСХОДЯТСЯ — первоклассный вывод, не сглаживать.** «Тут Ба Цзы видит лёгкость, а Джйотиш — напряжение; это значит честно: однозначного ответа нет», а не среднее по больнице.

**Структура `совместимость.md`:**
1. Шапка: даты рождения A и B + тип связи (без текущего возраста).
2. `## Самое главное` (4–6 строк) — 1–3 сильнейших сигнала (легче/труднее), приоритет кросс-системным сходимостям; + обязательная строка «насколько верить: немного — это призма архетипов, не диагноз; настоящая проверка — ваша жизнь вдвоём».
3. `## Как читать` (короткий хаб) — НЕ единый процент; три независимых языка, разные слои/шкалы, не складываются; окна и напряжение, не приговор; направленное = по-разному для A и B; что значат маркеры.
4. `## Где легче` — из `ease[]`, сгруппировано, обычными словами.
5. `## Где труднее` — из `friction[]`, честно (непогашенные доши, активный Марс, компромисс/доминирование в Дизайне Человека).
6. `## По-разному для A и B` — из `directional[]`: кто что несёт. Сюда теперь попадают и новые джйотиш-слои: насколько у каждого крепок его собственный «сектор партнёрства» (по-разному для A и B), и «наложение» — чьи качества в какие зоны жизни другого ложатся. Переводи в простой язык; полярность «благо/напряг» — **грубая тенденция, НЕ вердикт** (трудная планета в зоне часто значит «там интенсивно/важно», а не «плохо»). Не раздувай: наложений много — бери 1–3 самых выпуклых.
7. `## Где системы расходятся` — явные противоречия и ПОЧЕМУ (стихии vs планеты vs образы).
8. `## Тень` (обязательна) — что сгладил; где сходимость могла быть переоценена (общий корень систем); дом-знаковые ячейки Марса — один источник (AstroSage), средняя уверенность; **сила 7-го дома и наложение домов — грубые слои-тенденции, не вердикт**; хрупкость к точному времени; что пока НЕ считается (межкарточные аспекты, D9-синастрия, возрастные смягчения — см. ниже).
9. `## Что дальше` — окна для разговора, 3–5 примеров вопросов под темы этой пары; не обещание ответов.

Если роли жених/невеста условны (однополая пара / `jyotish.roles_defined=false` в `compat.json`) — веди направленные сигналы в ОБЕ стороны и помечай «роль условна», как это уже делает `compat.py`.

## Шаг 5.5. Гейт чистоты языка (детерминированный, с exit-кодом — как в /profile3)

Синтез изредка протаскивает спец-термин, балл или иероглиф мимо правил. Прогони линтер в compat-режиме (базовый словарь синтеза + жаргон совместимости: куты по именам, Мангал/доша, дришти/дустхана, синастрия/наложение, ретро/комбуст/сожжённый, управитель, ворота/каналы/авторитет + ЛЮБЫЕ баллы N/N и проценты):
```bash
python3 "$DIR/validate_synthesis.py" --compat "$OUT/совместимость.md"
```
- **HARD (exit 1)** — верни агенту на правку (одной фразой: «замени X на смысл обычными словами») до **ЗЕЛЁНО**; спот-чек, графики и PDF — только после.
- **SOFT (exit 0)** — двусмысленные слова (седьмой, компромисс, звезда, столп…): глазами реши — термин (переписать смыслом) или обычная речь (оставить).
Замены-образы («струны» вместо каналов, «искры» вместо электромагнетики) линтер не трогает — терминов в них нет. Ручной grep больше не нужен: прежний блок зависел от ugrep (`-P`) и не имел exit-кода.

## Шаг 5.6. Спот-чек фактов (смысл, не лексика)

Линтер не ловит смысловое враньё, а самый дорогой сбой этого жанра — перепутать, КТО кого. Отдельным агентом (чистый контекст, синтез не писал) сверь `совместимость.md` против `compat.json`: 8–10 утверждений, из них ОБЯЗАТЕЛЬНО все направленные («кто → кого» из `directional[]` — проверить, что A и B нигде не перевёрнуты), 2–3 из `ease[]`, 2–3 из `friction[]`, и что оговорки (`meta.marriage_systems_note`, если не null; `jyotish.marriage_caveat`) реально попали в текст. Вывод: утверждение → что говорит JSON → совпало/расхождение. Расхождения поправь ДО графиков. Это выборка: грубое враньё ловит, полноту не обещает.

## Шаг 5.7. Вписать графики (после финального текста, ДО PDF)

Когда текст `совместимость.md` готов и прошёл чистку (5.5) — допиши под него инфографику. Графики строит КОД из `_compat.json` (агент их НЕ рисует, как и числа), идут в КОНЕЦ файла секцией «## Графики к чтению»:
```bash
python3 "$DIR/infographics.py" "$OUT/_compat.json" --product compat --append-to "$OUT/совместимость.md"
```
Три графика, все из дайджеста, честные по построению:
- **Матрица сходимости** — домены × 3 системы: строка одного цвета = языки согласны, пёстрая = спорят, пусто = система молчит; скоба «общий корень» над Ба Цзы+Джйотиш (их согласие менее независимо); «?» у джйотиш-ячейки = плывёт при неточном времени A.
- **Поток A↔B** — кто кого тянет/питает: направление из `dir` (Ба Цзы) и `who` (ДЧ), НЕ оценка.
- **Ландшафт легче/труднее** — карта тем по системам (цвет точки = система), повтор свёрнут в «×N». НЕ счёт.

Честность вшита: НЕ единый %, НЕ вердикт; иероглифы из тем срезаются (`_strip_cjk` — CJK в SVG рендерится нестабильно, правило проекта); чего нет в данных — не дорисовывается. Идемпотентность — в коде (2026-07-15): `--append-to` видит существующий «## Графики к чтению» и не дублирует; опечатка в имени продукта — громкий exit 2. `infographics.py --test` — зелёный (включает 3 графика совместимости).

Графики — иллюстрации, текст первичен (идут ПОСЛЕ «Что дальше»). Графиков «синтеза» у нас нет (синтез профиля их тоже не имеет) — тут другое: эти три про ПАРУ и строятся из `compat.json`.

## Куда сохранять

Папка вывода: `$DIR/profiles/compat__<датаA>_<городA>__<датаB>_<городB>/` (создай; ASCII-разделитель `__` шелл-безопасен). Занята ДРУГИМ прогоном той же пары (ректификация времени, другой `--rel`) — добавь различающий суффикс `…__<метка>` (напр. `__A0635` — вариант времени A 06:35). Это ВЫВОД (можно), не данные людей (нельзя сохранять/запоминать).

Персисти туда по конвенции `_*.json`: `_compat.json` (полный вывод движка) + 6 входных `_A_bazi.json … _B_hd.json` (воспроизводимость). Плюс `совместимость.md` и `совместимость.pdf`. Плюс штамп версии движков: `{ date +%F; shasum -a 256 "$DIR"/*.py; } > "$OUT/_engines.sha"` — после баг-фикса кода кандидаты ищутся по старому отпечатку, точная проверка = пересчёт JSON и diff с сохранёнными `_*.json`.

В конце дай пользователю путь к `.md`/`.pdf` и 3–5 строк итога: 1–2 кросс-системные сходимости (где легче), 1–2 точки напряжения, и главную оговорку (хрупкость времени / тип связи).

## Что команда НЕ делает (честные границы — назови их в Тени)

- **Только 3 системы** (Ба Цзы / Джйотиш / Дизайн Человека). Матрица/Джунгци/Генные Ключи в сравнение не идут.
- **Джйотиш = Аштакута (Гуна Милан)** — популярный, но слабо-валидированный метод. Сверх 8 кут теперь считаются (информативно, НЕ в 36 очках): сила собственного 7-го дома каждого, наложение домов (синастрия-слой), состояние Марса (ретро/комбуст). По-прежнему НЕ считаются: межкарточные аспекты, навамша-D9-синастрия, Даракарака. Это осознанный скоуп, не баг.
- **Дом-знаковые отмены Марса (Мангал)** — один источник (семейство AstroSage), средняя уверенность на ячейку.
- **Возрастные смягчения** по-прежнему НЕ считаются — нет классической основы, верно не делать. (Ретро/комбуст Марса теперь учтены как информативный флаг спорной трактовки — очки не меняет.)
- **Предсказательная сила этих систем не установлена.** Инструмент структурирует разговор и показывает неопределённость — не предсказывает отношения. Не поднимай претензию выше этого.
- Не генерирует недостающий профиль (`/profile3`) человека (переиспользует, если есть).
