Годовой прогноз по Ба Цзы — анализ взаимодействия натальной карты с текущим/указанным годом.

## Аргументы

`ДАТА_РОЖДЕНИЯ ЧАС ПОЛ [ГОД] [UTC+N|город]` (в Claude Code — `/bazi-year …`)

Пример: `1990-05-15 14:30 М 2026 UTC+3`

Если год не указан — текущий год.

## Порядок работы

Корень проекта и интерпретатор — как в `../SKILL.md` (`BAZI`, `PY=$BAZI/.venv/bin/python`).

1. Рассчитай натальную карту с прогнозной датой: `"$PY" "$BAZI/bazi.py" ДАТА ЧАС ПОЛ --city ГОРОД --as-of ГОД-06-01 --json` (без города в базе — `UTC+N` вместо `--city`) — `--as-of` фиксирует год Ба Цзы (граница — Личунь) и текущий столп удачи; `current_year`/`dynamic_interactions` в JSON уже посчитаны для этого года
2. Определи текущий Столп Удачи (大运) для указанного года (из JSON)
3. Рассчитай годовой столп (流年) — из JSON `current_year`
4. Проведи трёхслойный анализ: Натал + Удача + Год

## Анализ (подробные правила — `../references/02-analysis.md`, раздел 3.11; взаимодействия — `03-interactions-stars.md`)

### 1. Годовой столп
- Стихия и Десятое Божество годового ствола → тема года
- Стихия и значение годовой ветви

### 2. Взаимодействие с натальной картой
- Столкновения (冲) годовой ветви с натальными
- Гармонии (合), наказания (刑)
- Комбинации годового ствола с натальными

### 3. Взаимодействие с текущим Столпом Удачи
- Удача + Год = двойной контекст
- 用神 появляется/исчезает?
- Активация Шэнь Ша (驿马, 桃花, 红鸾, 天喜)

### 4. Помесячный прогноз (краткий)
12 месяцев года — для каждого месяца определи столп месяца и его взаимодействие с годом + натальной картой. Выдели 2-3 лучших и 2-3 сложных месяца.

```
  Текущая Удача: [Ствол][Ветвь] (возраст X-X)

  Финансы: [...]

  ── Календарь месяцев ──
  [Таблица 12 месяцев с оценкой]

  ── Рекомендации ──
  [Благоприятные стихии, цвета, направления, тайминг]
```
