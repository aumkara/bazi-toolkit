### Летнее время и исторические часовые пояса (СССР/Россия)

**КРИТИЧЕСКИ ВАЖНО для рождений на территории бывшего СССР:**

**Декретное время (1930-1981):** В 1930 г. СССР перевёл часы на +1 час вперёд относительно поясного времени. Это «декретное время» (поясное + 1 час) действовало постоянно.

**Летнее время СССР (1981-1991):** С 1981 г. введено летнее время: +1 час к декретному (= поясное + 2 часа) с апреля по сентябрь.

**Россия 1992-2010:** Продолжала использовать декретное время зимой и летнее летом.

**Россия 2011-2014:** Постоянное «летнее» время (поясное + 2) круглый год. Отменено декретное.

**Россия с 26.10.2014:** Постоянное «зимнее» время (декретное = поясное + 1). Летнее отменено.

**Практическое правило:**

| Период | Зима | Лето | Поправка |
|--------|------|------|----------|
| До 1930 | Поясное | Поясное | 0 |
| 1930-1980 | Поясное+1 | Поясное+1 | -1 час от записанного |
| 1981-1991 | Поясное+1 | Поясное+2 | Зима: -1ч, Лето: -2ч |
| 1992-2010 | Поясное+1 | Поясное+2 | Зима: -1ч, Лето: -2ч |
| 2011-окт 2014 | Поясное+2 | Поясное+2 | -2 часа |
| С окт 2014 | Поясное+1 | Поясное+1 | -1 час |

**Что это значит для Ба Цзы:** Записанное время рождения в свидетельстве включает декретное/летнее смещение. Для истинного солнечного времени нужно:
1. Убрать декретное/летнее смещение (см. таблицу)
2. Применить поправку на долготу (из таблицы городов)
3. Применить уравнение времени

**Пример:** Рождение в Москве 15 июля 1985, 14:30 по часам:
- Летнее время: -2ч → 12:30 поясное
- Поправка долготы: -29.6 мин → 12:00
- Уравнение времени (июль): -4 мин → 11:56
- Истинное солнечное время: **11:56** → период 午 (11:00-13:00)

**Для Украины:** Летнее время с 1981. С 2014 — постоянное UTC+2 зимой, UTC+3 летом (EET/EEST).

**Для Китая:** Единый UTC+8 для всей страны с 1949. До 1949 — разные пояса. Летнее время 1986-1991. Для западного Китая (Синьцзян) реальная разница с UTC+8 может быть 2+ часа — обязательна корректировка.
