### 1.5. Шестидесятеричный цикл (六十甲子 Liushi Jiazi)

60 пар Ствол-Ветвь. Формула из позиции S (1-60):
```
stemIndex = 1 + ((S - 1) mod 10)
branchIndex = 1 + ((S - 1) mod 12)
```

Обратная формула (из Ствола T и Ветви B):
```
k = 6*T - 5*B
S = k > 0 ? k : k + 60
```

## ЧАСТЬ 2: АЛГОРИТМЫ РАСЧЁТА

### 2.1. Столп Года (年柱)

Год Ба Цзы начинается с **Ли Чунь (立春, Начало Весны, ~4 февраля)**, НЕ с 1 января и НЕ с Лунного Нового года.

**Формулы** (для григорианского года y):
```
yearStem = 1 + ((y + 6) mod 10)       → индекс ствола 1-10
yearBranch = 1 + ((y + 8) mod 12)     → индекс ветви 1-12
```

**КРИТИЧЕСКИ ВАЖНО:** Если дата рождения ДО Ли Чунь данного года, используй `y - 1`.

**Приблизительные даты Ли Чунь:** обычно 3-5 февраля. Для точного расчёта нужна астрономическая таблица (долгота Солнца = 315°).

### 2.3. Столп Дня (日柱)

Непрерывный счёт Ган-Чжи с древности. Вычисляется через **Юлианский Номер Дня (JDN)**.

**Шаг 1: Григорианская дата → JDN** (формула Флигеля-Ван Фландерна, целочисленная):
```
Для даты Y-M-D:
если M <= 2: Y = Y-1, M = M+12
A = floor(Y / 100)
B = 2 - A + floor(A / 4)
JDN = floor(365.25 * (Y + 4716)) + floor(30.6001 * (M + 1)) + D + B - 1524.5
```
Используй целый JDN для полудня даты.

**Шаг 2: JDN → позиция в цикле:**

Опорная дата: 27 января 2019 = 甲子 (S=1), JDN = 2458511.

```
S = 1 + ((JDN - 11) mod 60)              // mod(2458511, 60) = 11
dayStem = 1 + ((S - 1) mod 10)
dayBranch = 1 + ((S - 1) mod 12)
```

**Или напрямую из JDN:**
```
dayStem = 1 + ((JDN + 9) mod 10)       // (2458511 + 9) mod 10 = 0, +1 = 1 = 甲 ✓
dayBranch = 1 + ((JDN + 1) mod 12)     // (2458511 + 1) mod 12 = 0, +1 = 1 = 子 ✓
```

**Час Цзы (23:00–00:59) — школьный спор, ДВЕ конвенции:** (а) «день меняется в 23:00» — рождённому в 23:30 ставят столп СЛЕДУЮЩЕГО дня (и ствол часа от него); (б) «день меняется в полночь» (раздельный 早/晚子时) — день остаётся текущим, ветвь часа 子, а ствол 子-часа для 23:00–23:59 берётся **от следующего дня** (классическое «日柱当天、时柱按次日起»; так считают lunar-python и большинство排盘-программ). **bazi.py реализует (б)** — проверено: 23:30 15.05.1990 → день 庚辰 (15-е), час 戊子 (ствол от 辛 следующего дня). *До 2026-11-09 bazi.py брал ствол часа от текущего дня (丙子) — это был третий, нестандартный вариант; он остался флагом `--late-zi-hour-stem same_day` для сравнения со старыми чтениями; использованная конвенция всегда записана в JSON `conventions.late_zi_hour_stem`.* Для рождённых 23:00–23:59 карта КОНВЕНЦИОННО-ЗАВИСИМА: по школе (а) меняется столп дня, то есть сам Хозяин Дня — обязательно скажи это и покажи обе версии.
