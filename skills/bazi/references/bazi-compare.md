Анализ совместимости двух карт Ба Цзы (合婚 He Hun).

## Аргументы

`ДАТА1 ЧАС1 ПОЛ1 ДАТА2 ЧАС2 ПОЛ2 [UTC+N|город]` (в Claude Code — `/bazi-compare …`)

Пример: `1990-05-15 14:30 М 1992-08-20 10:00 Ж UTC+3`

## Порядок работы

1. Рассчитай обе карты через `bazi.py` (корень и интерпретатор — как в `../SKILL.md`):
```bash
BAZI="${BAZI_DIR:-$HOME/.bazi}"; PY="$BAZI/.venv/bin/python"
"$PY" "$BAZI/bazi.py" ДАТА1 ЧАС1 ПОЛ1 --city ГОРОД1 --json   # без города в базе — UTC+N
"$PY" "$BAZI/bazi.py" ДАТА2 ЧАС2 ПОЛ2 --city ГОРОД2 --json
```

2. Проведи анализ по 5 критериям (подробные правила — `../references/03-interactions-stars.md`, раздел 5.4; формат вывода — `../SKILL.md`, «Формат вывода для Совместимости»: markdown-таблица, не ASCII-рамка):

### Критерий 1: Стволы Дня (макс. 2 балла)
- 五合 (甲-己, 乙-庚, 丙-辛, 丁-壬, 戊-癸) → **2 балла**
- Та же стихия → **1.5**
- Порождающие стихии → **1**
- Контролирующие стихии → **0.5**
- Взаимный контроль → **0**

### Критерий 2: Ветви Дня (макс. 2 балла)
- 六合 (子丑, 寅亥, 卯戌, 辰酉, 巳申, 午未) → **2**
- 三合 (если есть третья ветвь) → **1.5**
- Нейтрально → **1**
- 六害 → **0.5**
- 六冲 → **0**
- 三刑 → **0**

### Критерий 3: Комплементарность стихий (макс. 2 балла)
- 用神 одного = сильная стихия другого → **2**
- Частичное дополнение → **1**
- Обе карты с одинаковым дисбалансом → **0.5**

### Критерий 4: Божества отношений (макс. 2 балла)
Для мужчины: 正财 = жена. Для женщины: 正官 = муж.
- Божество присутствует, сильное, не повреждённое → **2**
- Присутствует, но слабое или повреждённое → **1**
- Отсутствует → **0.5**

### Критерий 5: Дворцы супругов (макс. 2 балла)
- Ветвь дня (日支) благоприятна для обоих → **2**
- Нейтральна → **1**
- Столкновение или наказание → **0**

## Формат вывода

Только markdown-таблицей (не ASCII-рамкой в код-блоке — иероглифы двойной ширины ломают выравнивание, PDF выходит кривым). Иероглиф всегда в паре с русским:

| Критерий | Разбор | Оценка |
|---|---|---|
| Партнёр 1 | [ХД, стихия±, дата] | |
| Партнёр 2 | [ХД, стихия±, дата] | |
| 1. Стволы дня | [合/克/生/同 + русским] | X.X / 2 |
| 2. Ветви дня | [合/冲/害/刑 + русским] | X.X / 2 |
| 3. Стихии | [дополняют / конфликт] | X.X / 2 |
| 4. Божества | [正财 / 正官 — наличие, сила, повреждение] | X.X / 2 |
| 5. Дворцы супругов | [日支 обоих: благоприятна / нейтральна / удар] | X.X / 2 |
| **Итого** | [вердикт: Отлично / Хорошо / Средне / Сложно] | **X.X / 10** |

**Шкала:**
- 8-10: Отличная совместимость
- 6-7.5: Хорошая совместимость
- 4-5.5: Средняя, нужны усилия
- 0-3.5: Сложная, серьёзные конфликты
