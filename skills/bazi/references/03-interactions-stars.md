## ЧАСТЬ 4: ВЗАИМОДЕЙСТВИЯ ВЕТВЕЙ

### 4.1. Шесть Столкновений (六冲 Liu Chong)

Противоположные ветви (через 6 позиций) сталкиваются:
- 子-午 (Крыса-Лошадь) — Вода vs Огонь
- 丑-未 (Бык-Коза) — Земля vs Земля
- 寅-申 (Тигр-Обезьяна) — Дерево vs Металл
- 卯-酉 (Кролик-Петух) — Дерево vs Металл
- 辰-戌 (Дракон-Собака) — Земля vs Земля
- 巳-亥 (Змея-Свинья) — Огонь vs Вода

Столкновения = разрушение, конфликт, перемены, потери.

### 4.2. Шесть Гармоний (六合 Liu He)

Соседние по кругу ветви гармонируют:
- 子-丑 → Земля
- 寅-亥 → Дерево
- 卯-戌 → Огонь
- 辰-酉 → Металл
- 巳-申 → Вода
- 午-未 → Огонь (или Земля)

Гармонии = слияние, объединение, трансформация.

### 4.3. Тройная Гармония (三合 San He)

Три ветви одной стихиальной группы:
- 申子辰 → Вода (рама)
- 寅午戌 → Огонь (рама)
- 巳酉丑 → Металл (рама)
- 亥卯未 → Дерево (рама)

### 4.4. Три Наказания (三刑 San Xing)

- 寅-巳-申 — Наказание неблагодарности (恃势之刑)
- 丑-戌-未 — Наказание грубости (无恩之刑)
- 子-卯 — Наказание невежливости (无礼之刑)
- 辰-辰, 午-午, 酉-酉, 亥-亥 — Самонаказание (自刑)

### 4.5. Шесть Вредов (六害 Liu Hai)

Ветви, которые вредят друг другу (разрушают гармонию 六合):
- 子-未 (Крыса-Коза) — разрушает гармонию 子丑
- 丑-午 (Бык-Лошадь) — разрушает гармонию 午未
- 寅-巳 (Тигр-Змея) — разрушает гармонию 寅亥
- 卯-辰 (Кролик-Дракон) — разрушает гармонию 卯戌
- 申-亥 (Обезьяна-Свинья) — разрушает гармонию 巳申
- 酉-戌 (Петух-Собака) — разрушает гармонию 辰酉

Вред = скрытый ущерб, предательство, проблемы в отношениях, болезни.

### 4.6. Шесть Разрушений (六破 Liu Po)

Ветви, разрушающие друг друга:
- 子-酉 (Крыса-Петух)
- 丑-辰 (Бык-Дракон)
- 寅-亥 (Тигр-Свинья)
- 卯-午 (Кролик-Лошадь)
- 巳-申 (Змея-Обезьяна)
- 未-戌 (Коза-Собака)

Разрушение = потеря стабильности, разрыв, разочарование. Слабее столкновения, но ощутимо.

### 4.7. Пустота (空亡 Kong Wang)

60 Цзя Цзы делятся на 6 десятидневных циклов (旬 Xun). В каждом 旬 — 10 стволов на 12 ветвей, 2 ветви остаются «пустыми».

| Десятидневка (旬) | Пустые ветви (空亡) |
|-------------------|-------------------|
| 甲子旬 (甲子—癸酉) | 戌, 亥 |
| 甲戌旬 (甲戌—癸未) | 申, 酉 |
| 甲申旬 (甲申—癸巳) | 午, 未 |
| 甲午旬 (甲午—癸卯) | 辰, 巳 |
| 甲辰旬 (甲辰—癸丑) | 寅, 卯 |
| 甲寅旬 (甲寅—癸亥) | 子, 丑 |

**Определение:** Найди позицию Столпа Дня в цикле 60 → определи его 旬 → пустые ветви.

**Формула:** Для дня с позицией S в цикле:
```
xunStart = ((S - 1) // 10) * 10 + 1   // начало десятидневки
firstBranch = ((xunStart - 1) % 12)    // ветвь начала
emptyBranch1 = (firstBranch + 10) % 12
emptyBranch2 = (firstBranch + 11) % 12
```

**Значение:**
- Пустая ветвь в карте = «пустой» столп. Его влияние ослаблено или нестабильно.
- Пустота может быть «заполнена» (填实) при столкновении или в определённые годы/периоды.
- 空亡 в годовой ветви — нестабильные корни; в часовой — вопросы с детьми/подчинёнными.
- Благоприятная пустота: если «пустой» элемент неблагоприятен (忌神), пустота нейтрализует вред.

### 4.8. Комбинации Стволов (天干合 Tiangan He)

Пять комбинаций Стволов (五合):
- 甲-己 → Земля
- 乙-庚 → Металл
- 丙-辛 → Вода
- 丁-壬 → Дерево
- 戊-癸 → Огонь

### 4.9. Столкновения Стволов (天干冲)

Стволы одной стихии, но разной полярности, разделённые на 4 позиции:
- 甲-庚 (Дерево+ vs Металл+)
- 乙-辛 (Дерево- vs Металл-)
- 丙-壬 (Огонь+ vs Вода+)
- 丁-癸 (Огонь- vs Вода-)

### 5.4. Совместимость (合婚 He Hun)

При анализе совместимости двух карт проверяй:

**1. Совместимость Хозяев Дня (日主):**
- Пять Комбинаций Стволов (五合): 甲-己, 乙-庚, 丙-辛, 丁-壬, 戊-癸 — лучшая совместимость
- Та же стихия — понимание, но и конкуренция
- Порождающие стихии — забота (порождающий) и зависимость (порождаемый)
- Контролирующие стихии — напряжение, но и страсть

**2. Совместимость ветвей дня:**
- 六合 (Шесть Гармоний) — отличная совместимость: 子丑, 寅亥, 卯戌, 辰酉, 巳申, 午未
- 三合 (Тройная Гармония) — хорошая при наличии третьей ветви
- 六冲 (Столкновения) — конфликтная: 子午, 丑未, 寅申, 卯酉, 辰戌, 巳亥
- 六害 (Вред) — скрытые проблемы
- 三刑 (Наказания) — глубокие конфликты

**3. Комплементарность стихий:**
- Карты дополняют друг друга? Благоприятная стихия одного = сильная в карте другого?
- Один сильный ХД + один слабый = дисбаланс в отношениях

**4. Десять Божеств в контексте отношений:**
- Для мужчины: 正财 = жена, 偏财 = любовница
- Для женщины: 正官 = муж, 七杀 = любовник
- Наличие, сила и расположение этих Божеств указывают на характер отношений

**5. Дворцы супружества:**
- Ветвь дня = «дворец супруга» — что находится там, определяет характер брака
- Столкновение с дворцом супруга (в удаче или годовом столпе) = кризис отношений
