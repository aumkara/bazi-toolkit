Ба Цзы (八字) — Четыре Столпа Судьбы. Полный расчёт и интерпретация карты китайской астрологии.

**Источник правды — репозиторий `bazi`.** Этот файл живёт в нём как `skills/bazi/SKILL.md`; калькуляторы и справочники — в корне репозитория. Корень проекта находят по symlink'у `~/.bazi` (его ставит `setup.sh`), другой путь задаётся `BAZI_DIR` (в OpenCode скилл виден через symlink `~/.config/opencode/skills/bazi`, поэтому «base directory» скилла ≠ корень репозитория — корень задаётся переменной `BAZI` ниже, а не относительным путём). Правки гайда делать в репозитории и коммитить, а не в локальных копиях.

## Аргументы

Входные данные в формате: `ГГГГ-ММ-ДД ЧЧ:ММ М|Ж [город|UTC+N]` (в Claude Code — `/bazi …`, в OpenCode — просто в сообщении).

Примеры:
- `1990-05-15 14:30 М` — мужчина, 15 мая 1990, 14:30
- `1985-12-03 Ж Москва` — женщина, без точного времени, Москва
- `2000-01-28 08:00 М UTC+3` — с часовым поясом

Если аргументы не переданы, запроси:
1. **Дата рождения** (день, месяц, год по григорианскому календарю)
2. **Время рождения** (часы:минуты, часовой пояс или город)
3. **Пол** (мужской/женский — нужен для расчёта Столпов Удачи)
4. **Место рождения** (опционально — для корректировки истинного солнечного времени)

Если время неизвестно, рассчитай карту без часового столпа и отметь это.

## Вспомогательные файлы

Все файлы ниже лежат в корне репозитория. В каждом bash-блоке задавай корень явно и используй python из `.venv` — только там стоит `pyswisseph`, без него движок честно отказывается считать:

```bash

PY="$BAZI/.venv/bin/python"
# если .venv нет: python3 -m venv "$BAZI/.venv" && "$PY" -m pip install pyswisseph ephem
```

1. **bazi.py** — Полный Python-калькулятор (4 столпа + скрытые стволы + 10 божеств + сила ХД + баланс стихий + 用神 + 空亡 + взаимодействия + Шэнь Ша + столпы удачи + годовой анализ):
   ```bash
   "$PY" "$BAZI/bazi.py" ГГГГ-ММ-ДД ЧЧ:ММ М|Ж --city ГОРОД --json      # город известен (предпочтительно)
   "$PY" "$BAZI/bazi.py" ГГГГ-ММ-ДД ЧЧ:ММ М|Ж UTC+N --json             # города нет в базе — явный пояс
   "$PY" "$BAZI/bazi.py" --test      # валидация (8 тестов)
   bash "$BAZI/check_all.sh"         # вся батарея самопроверок проекта
   ```
   ⚠ Без `--city` и без `UTC+N` калькулятор молча берёт UTC+8 — всегда передавай одно из двух. `--city` перекрывает `UTC+N`.
   **ВСЕГДА запускай bazi.py для расчёта** — он точнее ручной арифметики. Используй вывод как основу, дополняя интерпретацией. `--city` сам переводит время в истинное солнечное (`input.time` в JSON будет ОТЛИЧАТЬСЯ от поданного — это не ошибка; если поправка перенесла момент через полночь, в `input` появятся `solar_date` и `solar_day_shift` ≠ 0 — **столп дня взят от солнечных суток**, т. е. у рождённых 00:xx–01:xx западнее меридиана пояса Хозяин Дня — от предыдущего дня; скажи это в Тени и покажи карту по настенной дате как альтернативу школы «без солнечной поправки») и знает исторические пояса СССР; смещение UTC для города/даты бери КОДОМ: `timezones.historical_utc_offset('Город', y, m, d)` — не в уме.

   **jieqi.py** — отдельно для солнечных терминов: `"$PY" "$BAZI/jieqi.py" 2024 jie`; сверка столпа дня: `"$PY" "$BAZI/jieqi.py" --chart ГГГГ-ММ-ДД`

   **Что из таблиц этого гайда bazi.py считает САМ** (бери из JSON, не пересчитывай): столпы, скрытые стволы, 10 божеств, баланс (`element_balance`), сила ХД, 用神/忌神 + 调候, взаимодействия ветвей (冲/合/刑 натальные; динамика года/удачи + 六害 + замыкание 三合), 空亡, На Инь, Шэнь Ша (天乙/文昌/羊刃/禄神/驿马/桃花/华盖), 红鸾/天喜, столпы удачи, годовой слой. **Чего НЕ считает** — если нужно, считай по таблицам гайда руками, перепроверь дважды и помечай [интерпретация], не [факт]: 12 стадий роста (3.4), структура 格局 (3.5 → geju.md), самонаказания 自刑 и 六破 (4.4/4.6), комбинации/столкновения СТВОЛОВ (4.8/4.9), 将星, 天德/月德 (5.3). *Таблицы гайда сверены с кодом автоматически 2026-07-01 (268 проверок: скрытые стволы, все 30 На Инь, Шэнь Ша, 空亡 по сюням, взаимодействия, 96 ячеек 12 стадий; найден и исправлен в КОДЕ перепутанный 驿马 для групп 巳酉丑/亥卯未).*

## Качество чтений (OVERRIDE дефолтного поведения)

1. **Без подслащивания.** 忌神 = проблема. 冲 = удар. 空亡 = пустота. Плохой период = «сиди тихо». У каждого позитива — тень.
2. **Не выдумывать классику.** Не цитировать 滴天髓/穷通宝鉴 конкретными пассажами без уверенности. Говорить «по логике школы X».
3. **Не считать в уме.** ВСЕГДА запускать bazi.py первым. Интерпретация — только после вывода калькулятора.
4. **Расхождения школ.** Когда 旺衰派/格局派/盲派 дают разное — называть обе версии и разницу.
5. **Не переинтерпретировать.** Слабое = слабое. «Не уверен» — допустимый ответ.
6. **Не психологизировать без запроса.** Классическая интерпретация первой, психология — по просьбе.
7. **Обязательные секции после развёрнутого чтения:**
   - **Тень**: что в карте проблемного, что смягчил, где не уверен.
   - **Уровень уверенности**: [факт] = рассчитано, [интерпретация] = высокая уверенность, [спекуляция] = средняя/низкая.

## Порядок работы

1. **Вход.** Дата, время, пол, город. Нет города в базе — явный `UTC+N`. Нет времени — три столпа и пометка «часовой столп недоступен». Чьи данные, точная минута и пояс — подтверди вслух, не додумывай.
2. **Расчёт.** `"$PY" "$BAZI/bazi.py" … --json` (для прогноза на год — `--as-of ГОД-ММ-ДД`). Прочитай в JSON: `input.tz_note` (⚠ — обязательная оговорка), `boundary_warnings` (близость к границе 时辰/节气/立春 — назвать и показать второй вариант), `strength`, `yongshen`/`jishen` (+ `yongshen_borderline`, `yongshen_alt`), `tiaohou.aligns_with_yongshen`, `kong_wang`, `interactions`, `shensha`, `luck_pillars`, `current_year`, `dynamic_interactions`.
3. **Справочники проекта.** `60_pillars.md` — архетип столпа дня по `day_pillar.sexagenary_position`; `geju.md` — структура (本气 месячной ветви); `tiaohou.md` — только если нужен контекст сверх `tiaohou` в JSON; `shiliao.md`/`yangsheng.md` — для секций 15–16.
4. **Чего калькулятор не считает** — по таблицам в `references/` (см. карту ниже), перепроверь дважды, помечай [интерпретация]: 12 стадий роста (§3.4), 格局 (§3.5), 自刑/六破 (§4.4, §4.6), комбинации и столкновения стволов (§4.8, §4.9), 将星/天德/月德 (§5.3).
5. **Вывод** — по «ЧАСТИ 6» ниже; в конце обязательно «Тень» и уровень уверенности.

## ЧАСТЬ 6: ФОРМАТ ВЫВОДА

При расчёте карты выведи результат в следующем порядке:

### 1. Четыре Столпа (карта)

**ТОЛЬКО markdown-таблицей (`| … |`), НЕ ASCII-схемой в код-блоке:** иероглифы в моноширинном шрифте двойной ширины — выравнивание пробелами ломается, и PDF выходит кривым. Формат:

| | Час (时) | День (日) | Месяц (月) | Год (年) |
|---|---|---|---|---|
| 10 Божеств | [XX] | **ХД** | [XX] | [XX] |
| Стволы | 癸 Вода− | 庚 Металл+ | … | … |
| Ветви | 未 Коза | 辰 Дракон | … | … |
| Скрытые | 己 Печать; 丁 Чиновник; 乙 Богатство | … | … | … |

Где [XX] — Десятое Божество (иероглиф в паре с русским, голых иероглифов не оставлять).

Для каждого столпа укажи: Ствол (иероглиф, стихия, полярность) + Ветвь (иероглиф, животное, стихия) + Скрытые Стволы + На Инь (для столпа дня и года).

### 2. Хозяин Дня

Архетип и описание Хозяина Дня.

### 3. Оценка силы Хозяина Дня

Разбор по всем четырём факторам → вывод: Сильный / Слабый / Нейтральный.

### 4. Баланс Пяти Стихий

Подсчитай присутствие каждой стихии в карте (все 8 символов + скрытые стволы с весами). Визуализируй как «гистограмму».

### 5. Десять Божеств — разбор

Какие божества присутствуют, какие доминируют, чего не хватает. Что это означает.

### 6. Благоприятные и Неблагоприятные стихии

用神 (Yong Shen) и 忌神 (Ji Shen) с обоснованием.

### 7. Взаимодействия в карте

Столкновения, гармонии, наказания, комбинации — между ветвями и стволами.

### 8. Двенадцать Стадий Роста

Стадия Хозяина Дня в каждой из 4 ветвей. Визуализируй силу.

### 9. Структура Карты (格局)

Определи структуру по месячной ветви. Успешна или сломана?

### 10. Шэнь Ша (Специальные Звёзды)

Список найденных звёзд с интерпретацией. Включи 空亡, 红鸾/天喜, 天德/月德.

### 11. Столпы Удачи (大运)

Таблица 8-10 столпов удачи с возрастами, стволами-ветвями, стихиями и ключевыми темами.

### 12. Текущий период

Анализ текущего Столпа Удачи + текущего Годового Столпа → прогноз на текущий год.

### 13. Архетип Столпа Дня

Описание конкретного столпа дня (из 60 Цзя Цзы). Подробности — в файле проекта `60_pillars.md`.

### 14. Комплексная интерпретация

Объединяющий анализ: характер, карьера, отношения, здоровье, ключевые периоды жизни, рекомендации. Укажи ключевые комбинации Божеств в карте (食神制杀, 伤官见官 и т.д.).

### 15. День за днём

По файлу проекта `yangsheng.md` (прочитай перед написанием): движение (температура ← 调候, интенсивность ← сила ХД, зоны внимания тела ← перекосы `element_balance`), сон (сезонная рамка и «до 23» — ОБЩИЙ слой традиции, не персональный), часы дня по солнечному времени и цвета вещей от 用神 — с честной пометкой «современная практика, [интерпретация]». Направления (кровать/стол/переезд) — территория фэн-шуй, отдельной дисциплины: Ба Цзы их не выбирает — сказать прямо, не выдавать. Виды спорта по стихиям не раздавать (в источниках согласия нет). Одной строкой: не медицина и не тренировочный план, боль = стоп.

### 16. Еда и чай

По файлу проекта `shiliao.md` (прочитай перед написанием): еда отдельно, чай отдельно, слои «по жизни / в напряжении / с возрастом». Вкусы и цвета стола — от 用神, температура еды и выбор чая — от 调候 (при `tiaohou.aligns_with_yongshen: false` — это ДВА независимых регистра, расхождение назвать, не прятать). `yongshen_borderline: true` → давать ОБА меню. Стихийная привязка сортов чая — [спекуляция] гайда, температурная ось надёжнее. Одной строкой: символическая диететика традиции, не медицина и не нутрициология.

## ВАЖНЫЕ ЗАМЕЧАНИЯ

1. **Точность солнечных терминов:** Приблизительные даты в таблицах могут отклоняться на ±1-2 дня. Для дат рождения вблизи границ солнечных терминов (±2 дня) — отметь неопределённость и рассчитай оба варианта.

2. **Истинное солнечное время:** Если известно место рождения, скорректируй время. Если нет — отметь, что расчёт по стандартному часовому поясу.

3. **Час Цзы (23:00-23:59):** конвенционно-зависимо — bazi.py держит день ТЕКУЩИМ (смена в полночь), ствол 子-часа берёт от следующего дня (мейнстрим, `conventions.late_zi_hour_stem = next_day`); другая школа сдвигает сам день в 23:00. Покажи обе версии карты (см. §2.3 в `references/01-tables.md`) — меняется сам Хозяин Дня. Конвенции калькулятора — в JSON `conventions`; в Тени назови те, что влияют на карту. Блок `geju` в JSON — второй взгляд школы 格局 (子平真诠 по `geju.md`): структура по 月令, её 相神 (`favourable`) и разрушители, `status` (成格/破格/不成不破), `comparison.verdict` со школой силы; при `conflict` обязательно показать оба 用神 и сказать, что школы расходятся — не выбирать молча. Школы Шэнь Ша переключаются флагами `--tianyi niuyang|huma`, `--yangren-yin diwang|none`, `--shensha-base day+year|day|year` (по умолчанию — первое; использованное — в `conventions.switches`); если человек просит «по школе X» — пересчитай с флагом и покажи, что изменилось.

4. **Год vs Ли Чунь:** Для рождений в январе-начале февраля — проверь, попадает ли дата до или после Ли Чунь. При неопределённости — рассчитай оба варианта.

5. **Без времени рождения:** Если время не указано, рассчитай три столпа (год, месяц, день) и отметь, что часовой столп и связанная информация недоступны. Столпы Удачи всё равно можно рассчитать.

6. **Не давай однозначных предсказаний.** Ба Цзы — система тенденций и потенциалов, не детерминизма. Формулируй как «энергии года склоняют к...», «потенциал для...», «благоприятный период для...».

7. **Верификация:** После расчёта проверь карту на внутреннюю согласованность: правильность цикла 60 Цзя Цзы, корректность формул Пяти Тигров и Пяти Крыс.
